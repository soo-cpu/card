개인정보처리방침

시행일 2026년 11월 28일

주식회사 홈퍼니싱(이하 "회사")은 '아르띠꼬 업로드' 앱을 운영하면서 아래와 같이 개인정보를 다룹니다.

1. 앱의 용도

'아르띠꼬 업로드'는 회사 직원이 회사 유튜브 채널에 시공 현장 영상을 올리기 위해 쓰는 내부용 앱입니다. 외부 고객이나 일반 사용자를 대상으로 하지 않습니다.

2. 다루는 정보

  • 회사 구글 계정으로 로그인할 때 받는 인증 토큰: 회사 유튜브 채널에 영상을 올리고 제목·설명·공개 시점을 정하는 데만 씁니다.
  • 회사가 올린 영상의 제목·업로드 기록: 같은 영상이 두 번 올라가지 않도록 확인하는 데 씁니다.

회사 외 다른 사용자의 개인정보는 수집하지 않습니다. 시청자 정보, 댓글 작성자 정보, 연락처 등은 받거나 저장하지 않습니다.

3. 보관과 삭제

인증 토큰은 회사 업무용 컴퓨터에만 보관하며 외부로 보내거나 다른 곳과 공유하지 않습니다. 앱 사용을 멈추면 토큰을 지우고, 구글 계정 설정(보안 → 타사 앱 액세스)에서 언제든 연결을 끊을 수 있습니다.

4. 구글 API 사용

이 앱은 YouTube Data API를 사용하며, 구글에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)에 맞게 위 용도로만 씁니다. 유튜브 이용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
