# 오늘의집 1·2차 상담 대행 지침 (회사 PC Claude용)

회사 PC의 Claude 데스크톱 앱이 크롬(Claude in Chrome)으로 오늘의집 파트너센터를 보고,
새 상담을 수락하고, 앱 채팅으로 1차·2차 상담까지 한다. 위임: 최윤수 대표 (2026-10-29).
상담 문구·가견적 계산은 **ohouse-consult 스킬**을 그대로 따른다.

---

## A. 처음 한 번 설정 (대표님)

1. 회사 PC에 **Claude 데스크톱 앱** 설치 → soo17115@gmail.com 계정으로 로그인
2. 크롬에 **Claude in Chrome** 확장 설치 → 같은 계정 로그인
3. 크롬에서 **오늘의집 파트너센터 로그인** (로그인 유지 체크)
   - PC 웹에서 상담 목록·수락·채팅이 되는지 먼저 확인. 앱에서만 된다면 이 방법은 못 씀 → 빠른 응대 툴(ohouse/)로 대체
4. 확장 프로그램에서 오늘의집 사이트 **허용**
5. PC **절전·화면 잠금 끄기** (켜져 있어야 일함)
6. 데스크톱 앱 새 대화에 아래 **C. 예약 작업 문구**를 붙여넣고 "이걸 평일·주말 08:30~20:30 30분마다 예약 작업으로 만들어줘"
7. 오늘의집 파트너 담당 매니저에게 "직원 대신 상담 보조 프로그램이 수락·답변해도 되는지" 한 번 확인

## B. 시험 운영 → 정식 운영

- **처음 3일 = 승인 모드:** 문구를 만들어 카톡(나와의 채팅)으로 대표님께 보내고, 대표님이 "보내"라고 하면 보낸다.
- **4일째부터 = 자동 모드:** 아래 규칙대로 바로 보내고, 보낸 내용을 카톡으로 알린다.
- 대표님이 "승인 모드로" / "자동 모드로" / "멈춰"라고 하면 바로 바꾼다.

## C. 예약 작업 문구 (복사해서 사용)

```
오늘의집 상담 대행을 한 번 돌려줘. 지침: card 저장소 ohouse/agent-guide.md, 문구·가견적: ohouse-consult 스킬.
모드: 승인 모드  (자동 모드로 바꾸면 여기만 수정)

1. 크롬: tabs_context 확인 → 새 탭에서 오늘의집 파트너센터 상담 목록 열기
2. 새 상담 요청: 수락 → 고객 정보 읽기 → 0단계 정보요청 문구(빠진 것만) → 오늘의집 채팅으로 발송
3. 고객 답장이 온 상담: 1단계 정리 → 정보 부족하면 빠진 것만 한 번 더 질문 / 충분하면 2차(가견적 범위 + 실측 일정 제안) 발송 → 정진혁 실장 인계 메모
4. 하루 지나도 답 없는 상담: 미응답 문구 1회만
5. 멈춤 조건에 걸리면 고객에겐 "담당 실장님이 직접 연락드리겠습니다"만 보내고 대표님께 알림
6. 처리 결과를 카카오톡 나와의 채팅으로 요약, 옵시디언 daily note에 조각 기록
7. 만든 탭 닫기. 새 상담·답장이 없으면 아무 알림도 보내지 말 것
```

## D. 1차 상담 (수락 직후)

- ohouse-consult **0단계** 문구 중 문의 종류에 맞는 것, 이미 아는 정보는 빼고 질문 4~8개.
- 사진(현재 집·참고 이미지) 요청 꼭 넣기.
- 오늘의집 채팅에는 **전화번호·외부 링크를 넣지 않는다** (오늘의집 정책). 고객이 통화를 원하면
  "편하신 시간 알려주시면 담당 실장님이 연락드리겠습니다"로 답하고 대표님께 알린다.

## E. 2차 상담 (고객 답장 후)

- 평형·공사 범위가 있으면 ohouse-consult **2~3단계**: 가견적 범위(총액 90~115%, 만원 단위) 안내.
- 샷시·확장·구조변경은 "실측 후 확정" 꼭 적기.
- 실측 일정은 **제안만**: "실장님이 OO시간에 연락드려 실측 일정 잡아드리겠습니다."
- 지급 조건을 물으면: 계약 시 디자인비 1차, 이후 2차 40%, 3차 40%, 4차(잔금) 20%.
- 2차를 보내면 **4단계 인계 메모**를 정진혁 실장 + 대표님께 카톡으로.

## F. 멈추고 사람에게 넘기는 경우 (Claude가 답하지 않음)

- 할인·가격 흥정, 계약 조건, 공사 기간·날짜 약속, 확정 견적 요구
- 불만·환불·하자·분쟁, 법적인 이야기
- 고객이 "사람과 통화하고 싶다", 화가 났거나 내용이 애매함
- 상가·사무실·관공서 등 주거가 아닌 공사, 예산이 단가표와 크게 다름(50% 미만)
- 사진만 보내고 내용이 없을 때 (사진 판단은 실장님)

## G. 안전 규칙

- 발송 시간: **08:30~20:30**만. 밤에 온 답장은 다음 날 아침에.
- 같은 고객에게 답 없이 연속 2통 넘게 보내지 않는다 (1차 + 미응답 1회까지).
- 계정 설정·결제·광고·리뷰·포트폴리오는 **건드리지 않는다**. 상담 목록과 채팅만.
- 삭제·거절·차단 버튼은 누르지 않는다. 확인 창이 뜨는 버튼은 피한다.
- 고객 연락처·주소는 카톡 알림과 옵시디언에 **이름·지역·평형만**, 전화번호 전체는 쓰지 않는다 (인계 메모는 예외: 실장님께만).
- 같은 동작이 2~3번 실패하거나 화면이 예상과 다르면 멈추고 대표님께 알린다.
