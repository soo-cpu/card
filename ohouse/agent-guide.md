# 오늘의집 1·2차 상담 대행 지침 (회사 PC Claude용) · v2 휴대폰 발송 방식

회사 PC의 Claude 데스크톱 앱이 크롬(Claude in Chrome)으로 오늘의집 사장님센터를 보고,
새 상담의 고객 문자를 **만들어서 대표님 카톡으로 보낸다.** 고객에게 보내는 건 **대표님이 휴대폰으로** 한다.
위임: 최윤수 대표 (2026-10-29). 문구·가견적 계산은 **ohouse-consult 스킬**을 그대로 따른다.

> **v2에서 바뀐 점 (2026-10-30)**
> - 10/29 시험에서 확인: 간편매칭은 '수락' 단계 없이 이미 매칭완료, 고객 채팅방 없음,
>   고객 연락은 상담 상세의 **전화하기/문자하기(0503 안심번호)** 뿐이고, PC에서는 '문자하기'가 열리지 않음.
> - 그래서 Claude는 고객에게 직접 보내지 않는다. **문구 + 안심번호를 카톡(나와의 채팅)으로 대표님께 보내고, 대표님이 휴대폰 문자로 복사해 보낸다.**
> - 승인 모드/자동 모드 구분 없음. 대표님이 보내는 것 자체가 승인이다.

---

## A. 처음 한 번 설정 (대표님, 회사 PC 앞에서 약 10분)

1. 회사 PC에 **Claude 데스크톱 앱** + 크롬 **Claude in Chrome** 확장 → 같은 계정 로그인 (10/29 완료)
2. 크롬에서 **오늘의집 사장님센터 로그인** (로그인 유지 체크) (10/29 완료)
3. PC **절전·화면 잠금 끄기** (켜져 있어야 일함)
4. 카카오톡 연결(PlayMCP 카톡 나와의 채팅)이 데스크톱 앱에서 되는지 확인
5. 데스크톱 앱 새 대화에 아래 **C. 예약 작업 문구**를 붙여넣고
   "이걸 매일 08:30~20:30 30분마다 예약 작업으로 만들어줘" ← **아직 안 함. 이게 빠져서 자동 실행이 안 됐음**

## B. 하루 흐름

```
새 상담 들어옴 (사장님센터)
  → Claude: 상담 상세 읽기 → 1차 문자 만들기 → 카톡으로 대표님께 [문구 + 0503 번호]
  → 대표님: 휴대폰에서 0503 번호로 문자 붙여넣어 발송 (1분)
  → 고객 답장은 대표님 휴대폰 문자로 옴
  → 대표님: 답장을 Claude(휴대폰 대화 또는 빠른 응대 툴)에 붙여넣기
  → Claude: 2차 문자(가견적 범위 + 실측 일정 제안) + 정진혁 실장 인계 메모
```

- 고객 답장은 대표님 휴대폰으로 오기 때문에 **회사 PC Claude는 답장을 볼 수 없다.**
  2차 상담은 대표님이 답장을 붙여넣을 때 만든다 (휴대폰 Claude 대화나 `ohouse/index.html` 빠른 응대 툴 사용).
- 사장님센터 상담 메모/상태 칸에 고객 답장이 적혀 있으면, 회사 PC Claude가 그걸로 2차 문자를 만들어도 된다.

## C. 예약 작업 문구 (복사해서 사용)

```
오늘의집 상담 대행을 한 번 돌려줘.
지침: https://raw.githubusercontent.com/soo-cpu/card/claude/todayhouse-automation-check-yxa3ss/ohouse/agent-guide.md
이 링크를 열어 읽고 그대로 따라줘. 문구·가견적은 ohouse-consult 스킬.

1. 발송 시간(08:30~20:30)이 아니면 아무것도 하지 말고 끝내기
2. 크롬: tabs_context 확인 → 새 탭에서 오늘의집 사장님센터 상담 목록 열기
3. 이미 카톡으로 보낸 상담은 옵시디언 '오늘의집 발송 기록'에서 확인해 빼기
4. 새 상담(수락 버튼이 있으면 수락 먼저): 상담 상세 읽기 → 1차 정보요청 문자(빠진 것만)
   → 카톡 나와의 채팅으로 [고객 문자 + 0503 안심번호] 보내기
5. 사장님센터 메모에 고객 답장이 적힌 상담: 2차 문자 + 정진혁 실장 인계 메모를 카톡으로
6. 1차를 보낸 지 하루 지났는데 사장님센터 상태가 그대로면: 미응답 문자 1회만 카톡으로
7. 멈춤 조건(F)에 걸리면 문구 대신 "사람 필요" 알림만 카톡으로
8. 옵시디언 '오늘의집 발송 기록'과 daily note 조각에 기록
9. 만든 탭 닫기. 새 상담이 없으면 카톡·기록 아무것도 남기지 말 것
```

## D. 1차 문자 (새 상담)

- ohouse-consult **0단계** 문구 중 문의 종류에 맞는 것. 이미 아는 정보는 빼고 질문 4~8개.
- 사진(현재 집·참고 이미지) 요청 꼭 넣기.
- 문자 끝에 **"추가 문의: 대표번호 1566-5904"** + **공통 홍보 문구**(블로그·오늘의집·유튜브·인스타·네이버 플레이스 링크).
  휴대폰 문자라서 번호·링크를 넣어도 된다. (오늘의집 앱 안 소개글·사진에는 여전히 번호 금지)
- 고객이 통화 시간을 적어 두었으면(예: "저녁 18시 이후") 카톡 알림 맨 위에 표시.

## E. 2차 문자 (고객 답장 후)

- 평형·공사 범위가 있으면 ohouse-consult **2~3단계**: 가견적 범위(만원 단위) 안내 + "현장 상황에 따라 금액이 달라질 수 있습니다".
- 샷시·확장·구조변경은 "실측 후 확정" 꼭 적기.
- 실측 일정은 **제안만**: "담당 실장님이 OO시에 연락드려 실측 일정 잡아드리겠습니다."
- 지급 조건을 물으면: 계약 시 디자인비 1차, 이후 2차 40%, 3차 40%, 4차(잔금) 20%.
- 2차 문자와 함께 **4단계 인계 메모**를 카톡으로 (대표님이 정진혁 실장에게 전달).

## F. 문구를 만들지 않고 "사람 필요"로 넘기는 경우

- 할인·가격 흥정, 계약 조건, 공사 기간·날짜 약속, 확정 견적 요구
- 불만·환불·하자·분쟁, 법적인 이야기
- 고객이 통화를 원함, 화가 났거나 내용이 애매함
- 상가·사무실·관공서 등 주거가 아닌 공사, 예산이 단가표와 크게 다름(50% 미만)
- 사진만 있고 내용이 없을 때 (사진 판단은 실장님)

## G. 안전 규칙

- 카톡 알림 시간: **08:30~20:30**만. 밤에 들어온 상담은 다음 날 08:30 첫 실행에서.
- 같은 고객에 대해 문구는 1차 + 미응답 1회까지만 만든다.
- 사장님센터에서는 **읽기와 '수락'만.** 전화하기·문자하기·삭제·거절·차단·계정 설정·결제·광고·리뷰는 누르지 않는다.
- 같은 동작이 2~3번 실패하거나 화면이 예상과 다르면 멈추고 대표님께 카톡으로 알린다.
- 카톡에는 0503 **안심번호만** 적는다 (고객 실제 번호가 보이면 적지 않음). 옵시디언에는 이름(성○○)·지역·평형만, 번호는 적지 않는다.

## H. 카톡 형식 (나와의 채팅, 1통 200자 제한 → 나눠 보냄)

상담 1건당:
```
[오늘의집 1차 ①/N] 이○○ · 중랑구 25평 전체
📞 0503-XXXX-XXXX ← 이 번호로 문자 보내주세요
(통화 희망: 저녁 18시 이후)
```
```
[오늘의집 1차 ②/N]
(고객에게 보낼 문자 본문 — 그대로 복사)
```
```
[오늘의집 1차 N/N]
(나머지 본문 + 대표번호 1566-5904 + 홍보 문구)
```
- 본문이 200자를 넘으면 문장 단위로 끊어 ②, ③… 으로. 대표님이 순서대로 이어 붙이면 문자 1통이 되도록.
- 실행 1회에 상담이 여러 건이면 맨 앞에 요약 1통: `[오늘의집 HH:MM] 새 상담 N건 · 사람 필요 N건`

## I. 기록

- 옵시디언 `오늘의집 발송 기록.md` (daily note 폴더 옆, 없으면 만들기)에 한 줄씩 덧붙이기:
  `2026-10-30 09:00 | 이○○ | 중랑구 25평 | 1차 문구 카톡 전송`
- 다음 실행 때 이 기록으로 이미 보낸 상담을 빼고, 하루 지난 미응답 건을 찾는다.
- daily note 조각: `_조각 YYYY-MM-DD HHMM 오늘의집 상담 대행.md` (처리한 건이 있을 때만).
