## 1. 잘 되는 인테리어 회사 운영 기준

### 1-1. 공통점 6가지

| # | 기준 | 잘 되는 회사는 이렇게 한다 | 왜 마진에 영향이 큰가 |
|---|---|---|---|
| 1 | **전문 분야 집중** | "30평대 구축 아파트 전체 리모델링", "40평 이상 하이엔드 주거"처럼 고객·평형·스타일을 좁힘 | 같은 유형 반복 → 공정·자재·하자 패턴이 익어서 원가가 내려감, 포트폴리오가 쌓임 |
| 2 | **견적 표준화** | 공정별 표준 단가표(철거·설비·목공·도장·타일·전기·가구…)를 두고 상담 때 바로 가견적 | 견적 시간 단축, 직원이 대표 없이 견적, 단가 누락(=손실) 방지 |
| 3 | **현장 원가 주간 관리** | 현장마다 "계약금액 / 실행예산 / 이번 주까지 쓴 돈 / 남은 예상 원가"를 매주 확인 | 적자는 공사 끝나고 아는 게 아니라 **중간에 막아야** 함. 추가공사 청구 누락도 여기서 잡힘 |
| 4 | **소개·후기 관리** | 준공 사진·영상, 고객 후기, 1년 점검(A/S) 방문을 체계적으로 | 하이엔드 고객은 광고보다 **지인 소개**로 옴. 소개 1건 = 광고비 0원 |
| 5 | **대표는 영업·관계에 집중** | 현장 관리·견적·발주는 실장/팀장에게, 대표는 고객 미팅·인맥·협업처 관리 | 대표 시간이 현장에 묶이면 큰 현장을 따올 시간이 없음 |
| 6 | **협력업체 고정 팀** | 공정별 1순위·2순위 업체를 고정, 일정 우선 배정과 결제일 약속을 맞바꿈 | 품질 일정 → 하자 감소, 단가 협상력, 하이엔드 마감 품질 유지 |

#### 숫자로 보는 현재 위치 (예시 계산 `[추정]` — 실제 숫자로 바꿀 것)

- 손익분기 매출 = **연 고정비 ÷ 마진율**
- 예) 고정비 월 2,500만 원(인건비 4명 + 임대 2곳 + 차량·기타) → 연 3억 원
  - 마진율 20%면 손익분기 매출 **15억**, 28%면 **10.7억**
- 즉, 마진율 8%p 올리는 것 = 매출 4억 더 하는 것과 같은 효과.
- 하이엔드 1건(예: 50평 × 평당 400만 = 2억, 마진 30%) = 6,000만 원 이익 = 일반 아파트 30평(6,000만, 마진 18%) **약 5~6건분**.

## 2. 하이엔드 공사로 가는 방법

### 2-1. 필요한 것

#### ① 실장급 디자이너 — 정규직 vs 프리랜서

| 항목 | 정규직 실장 | 프리랜서 (현장별 계약) |
|---|---|---|
| 비용 | 연봉 5,000~7,000만 + 4대보험 등 약 10% `[추정]` | 현장별: 디자인비의 50~70% 또는 공사비의 3~5% `[추정]` |
| 고정비 | 늘어남 (현장 없어도 나감) | 없음 (현장 있을 때만) |
| 브랜드 일관성 | 높음 — "아르띠꼬 스타일"을 만들 수 있음 | 낮음 — 디자이너마다 스타일 다름 |
| 현장 관리 | 직접 시킬 수 있음 | 보통 디자인·감리까지만, 현장 관리는 우리 몫 |
| 위험 | 일이 없으면 손실 | 좋은 디자이너는 바빠서 일정 안 맞음, 포트폴리오 소유권 분쟁 |
| 추천 시점 | 하이엔드 연 4건 이상 확보 후 | **지금 ~ 첫 1년** |

**추천:** 1년차는 프리랜서 1~2명과 **"현장별 계약 + 포트폴리오 사용권은 회사"** 조건으로 시작 → 하이엔드 계약이 연 4건 넘으면 그중 잘 맞는 사람을 정규직 제안.

#### ② 디자인비 별도 청구 구조

| 단계 | 내용 | 금액 기준 `[추정]` |

| 감리·디자인 관리 | 현장 마감 체크, 자재 확정 | 공사비의 3~5% 또는 디자인비의 30~50% |

- 시장 참고: 주거 디자인비 평당 30~80만 원 수준이라는 마켓 안내가 있으나 출처 신뢰도 낮음 (https://kmong.com/prices/%EC%9D%B8%ED%85%8C%EB%A6%AC%EC%96%B4) `[확인 필요]`

- **우리 시작점 제안:** 평당 10만 원부터 받고, 공사 계약 시 일부 차감(3-3 참고). 받는 습관을 먼저 만드는 게 목적.

#### ③ 대표 포트폴리오 1~2건 (전문 사진·영상)

- 전문 건축사진 작가 촬영: 1현장 50~150만 원 `[추정]`, 영상(1~2분 + 릴스 3개) 100~300만 원 `[추정]`
- 촬영 전 스타일링(가구·소품·꽃) 필수 — 대여 또는 쇼룸 소품 재활용
- 결과물 사용처: 홈페이지 메인, 인스타, 디자인 제안서, 갈매 쇼룸 모니터, 지명원(주거 실적 페이지)
- 고객 동의서(사진 공개·주소 비공개) 계약서에 포함

#### ④ 고급 마감 협력업체

| 공정 | 하이엔드에서 보는 포인트 | 할 일 |
|---|---|---|
| 무늬목 | 결 맞춤(북매치), 문·벽·가구 결 연결 | 무늬목 전문 가구공장 2곳 견적·샘플 |
| 도장 | 특수도장(베네치안·석회·마이크로시멘트), 붓자국 없는 도어 도장 | 특수도장 시공팀 1곳, 샘플판 제작 |
| 석재 | 대형 세라믹·천연석 북매치, 상판 일체형 | 석재 가공 업체 1곳 (슬랩 창고 방문) |
| 조명 | 간접조명 라인, 디밍, 색온도 | 조명 설계 가능한 전기팀 or 조명 디자이너 협업 |

- 각 공정 **1순위·2순위 업체**를 정하고, 갈매 쇼룸 시공을 "시험 현장"으로 맡겨 실력 검증.

#### ⑤ 상담 방식 — 디자인 제안서·자재 샘플·3D 렌더링

1. **사전 질문지** (예약 시 온라인): 평형, 가족 구성, 예산, 원하는 분위기 사진 3장
2. **1차 상담 (쇼룸, 60~90분)**: 포트폴리오 → 자재 샘플 벽에서 마감 고르기 → 예산 범위 안내
3. **디자인 계약** → 실측 → **2차 상담**: 평면 2안 + 3D 렌더링 + 자재 보드(실물 샘플 박스)
4. **공사 계약**: 상세 견적(공정별 표준 단가 기반) + 공정표
5. **준공**: 촬영 → 후기 요청 → 1년 점검

## 3. 구리 갈매 하이엔드 쇼룸 (예약제 상담)

### 3-1. 상봉 vs 갈매 역할 나누기

| | 상봉 전시장 | 갈매 쇼룸 |
|---|---|---|
| 브랜드 | 한샘·홈퍼니싱 | 아르띠꼬스튜디오 |
| 고객 | 일반 아파트, 부엌·욕실·부분 공사 | 전체 리모델링 40평+, 단독·타운하우스 |
| 운영 | 상시 오픈 (워크인) | **예약제만**, 상주 직원 없음 |
| 상담 | 제품·가격 위주 | 디자인·자재·공간 경험 위주 |
| 넘겨주기 | 상봉에서 고급 수요 고객 발견 → 갈매 예약 연결 | 갈매에서 예산 작은 고객 → 상봉 연결 |

### 3-2. 상주 없이 운영하는 방법

- 예약 들어오면 담당자(대표 or 실장)가 30분 전 도착, 조명·음악·온도 세팅 (스마트 조명·스위치로 원격 켜기)
- 주 2~3회 고정 상담 시간대 운영 (예: 화·목 오후, 토 오전) — 예약을 몰아서 이동 시간 절약
- 출입: 디지털 도어락 + CCTV, 상담 후 정리 체크리스트

### 3-3. 예약 받는 길

| 채널 | 방법 | 비용 |
|---|---|---|
| **네이버 플레이스 + 네이버 예약** | 스마트플레이스에 갈매 쇼룸 등록 → 예약 상품 "하이엔드 디자인 상담 (60분)" 생성, 시간대 지정 | 예약 무료, 결제 시 수수료 `[확인 필요]` |
| 홈페이지 | '예약 상담' 버튼 → 네이버 예약 링크로 연결 (예약 창구 1개로 통일) | 없음 |
| 인스타그램 | 프로필 '예약하기' 버튼에 네이버 예약 링크 | 없음 |
| 대표 인맥 | 카톡으로 예약 링크 직접 전달 | 없음 |

- 네이버 예약은 예약금·결제 설정 기능이 있으나 업종 유형별로 다름 (식당형 예약금 기능 보도: https://m.ddaily.co.kr/page/view/2026091417103589844). **상담 업종에서 예약금 받기 가능 여부는 스마트플레이스 센터에서 확인 필요** `[확인 필요]`

### 3-4. 상담비·디자인 계약금 방식 비교

| 방식 | 내용 | 장점 | 단점 | 추천 |
|---|---|---|---|---|
| A. 무료 상담 | 1차 상담 무료, 디자인 계약부터 유료 | 예약 많이 들어옴 | 구경만 하는 고객, 시간 낭비 | 첫 3개월 (데이터 쌓기) |
| B. 상담비 (예: 10~20만 원) → 계약 시 공사비에서 차감 | 예약 때 결제 | 진지한 고객만 옴 | 예약 수 줄어듦, 결제 기능 확인 필요 | 인맥 소개 고객엔 면제 |
| C. **디자인 계약금 (예: 디자인비의 50%, 200~400만 원)** → 공사 계약 시 디자인비 일부/전부 차감 | 1차 상담은 무료, 2차(실측·3D)부터 유료 | 업계에서 흔한 구조, 디자인 노동 보호 | 차감 범위 설명 필요 | **기본안** |

- **추천 조합:** 1차 상담 무료(예약제) + **디자인 계약금 받고 공사 계약 시 50% 차감** (100% 차감하면 사실상 무료 디자인이 됨)
- 계약서에 "공사 계약 안 할 경우 디자인비 환불 없음, 도면·렌더 사용 범위" 명시 — 디자인비 차감·환불 분쟁 주의 사례 참고 (https://wikidocs.net/blog/@knarchive/14160/)
- 업계 사례: 실측·디자인 미팅부터 시안비 발생, 공사 계약 시 전액 차감 (https://maily.so/tkdd/posts/2nznjx0mrp5) `[확인 필요: 업체 홍보성 자료]`

### 3-5. 쇼룸 꾸미는 단계별 안 (비용 전부 `[추정]`, 자체 시공 원가 기준)

| 단계 | 시기 | 구성 | 대략 비용 |
|---|---|---|---|
| **1단계** | 첫 3~6개월 | **핵심 공간 1개** (주방+다이닝 또는 거실 한 면, 약 8~12평) + **자재 샘플 벽** (무늬목·석재·도장·타일·하드웨어, 교체형 패널) + 상담 테이블 1개 + 모니터(포트폴리오·3D) | 4,000만~7,000만 원 |
| 1단계 내역 | | 핵심 공간 시공 2,500~4,500만 / 샘플 벽 500~1,000만 / 조명·스마트 제어 300~700만 / 가구·소품 500~1,000만 / 사진 촬영 100~200만 | |
| **2단계** | 하이엔드 계약 2~3건 후 | 두 번째 공간 (욕실 또는 드레스룸 or 침실) + 샘플 라이브러리(서랍형 자재 박스) | +3,000만~5,000만 원 |
| **3단계** | 연 하이엔드 4건+ | 전체 레이아웃 정리, 소규모 초대 행사 공간(6~10명), 협력업체 공동 전시(조명·가구 브랜드 협찬) | +2,000만~5,000만 원 (협찬으로 일부 상쇄) |

- 협력업체(석재·무늬목·조명)에 **샘플·시공 일부 협찬**을 받고, 대신 쇼룸에 업체 이름 표기 → 1단계 비용 20~30% 절감 가능 `[추정]`
- 쇼룸 자체를 포트폴리오 1호로 촬영 → 2-1 ③과 연결
