# 아르띠꼬 간편 견적 (고객용 + 승인용)

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `estimate/` | 고객 | 주소로 우리 집 찾기 → 공사 고르기 → **예상 범위만** 확인 → 상세 견적 신청 |
| `estimate/admin.html` | 대표 · 영업실장 · 디자인실장 | 비밀번호로 단가 열기 → 항목 조정 → **승인** → 잠긴 견적서 링크 + 문자 문구 |
| `quote/` | 고객 | 받은 링크에 휴대폰 뒤 4자리를 넣어야 견적서가 열림 |

## 보안 구조
- 고객 화면(`rates.js`)에는 **선택지별 묶음 금액**만 있고, 항목별 단가 184개는 없습니다.
- 항목 단가는 `prices.enc.js`에 **암호화**되어 있어 직원 비밀번호로만 열립니다. 사람마다 비밀번호가 따로 있고, 누가 승인했는지 견적서 아래에 찍힙니다.
- 신청 내용은 홈페이지 상담 폼과 같은 방식으로 artico_studio@naver.com 메일로 갑니다. 메일 속 「승인 화면」 링크를 누르면 바로 불러와집니다.
- 견적서 링크는 고객 휴대폰 뒤 4자리로 잠깁니다. 공정별 금액만 보이고 단가는 보이지 않습니다.

## 단가를 바꿀 때
단가표(JSON)를 고친 뒤 `node estimate/tools/build.mjs 단가표.json . 직원비밀번호.json`을 실행하면 `rates.js`와 `prices.enc.js`가 새로 만들어집니다. 단가표와 비밀번호 파일은 **저장소에 올리지 마세요.** (Claude에게 "간편견적 단가 바꿔줘"라고 하면 됩니다.)

## 선택지 바꾸기
`choices.js` — 공간별 선택지와 각 선택이 어떤 단가표 항목으로 바뀌는지. 금액은 없습니다.

## 우리 집 찾기
`plans.js` — 회사가 가진 단지·평면 타입 목록. 카카오 JavaScript 키를 넣으면 목록에 없는 단지도 주소로 찾아집니다 (방법은 파일 맨 위에 적혀 있음).
