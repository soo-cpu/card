# 야간 디자인 사례 캡처 — 사용설명서 2026-10-31 v1

매일 새벽 2시에 오늘의집·핀터레스트·인테리어 블로그에서 아파트·관공서 인테리어 사례를 찾아
**최대 5건**을 전체 화면 PNG로 캡처하고, 구글 드라이브에 날짜별로 정리합니다.

## v1에서 바뀐 점
- 실행이 끝나면 옵시디언 결과 목록에 한 줄 자동 추가
- v0을 이미 설치했다면 작업 스케줄러에서 `디자인사례캡처 2026-10-31 v0` 작업을 '사용 안 함'으로 바꾸고 v1 bat을 실행하세요.

## 설치 (윈도우 PC에서 한 번만)
1. 이 `design-capture` 폴더를 PC의 고정된 위치(예: `문서\디자인사례캡처`)에 내려받습니다.
   ※ 설치 후 폴더를 옮기면 예약 작업이 파일을 못 찾습니다.
2. 구글 드라이브 데스크톱 앱이 켜져 있고 로그인돼 있는지 확인합니다.
3. **`더블클릭 설치 2026-10-31 v1.bat`** 를 더블클릭합니다. 아래가 자동으로 진행됩니다.
   - 파이썬 설치(없을 때만) → Playwright·크로미움 설치
   - `내 드라이브\Claude 자료함\디자인 사례` 폴더 확인(없으면 생성)
   - 전원 옵션의 "절전 모드 해제 타이머 허용" 켜기
   - 작업 스케줄러에 `디자인사례캡처 2026-10-31 v1` 등록 (매일 02:00, 절전 중이면 깨워서 실행)
   - 마지막에 "지금 시험 실행?" → Y 를 누르면 바로 한 번 돌려 결과 폴더를 열어 줍니다.

## 결과물
`내 드라이브\Claude 자료함\디자인 사례\YYYY-MM-DD\`
- `사례01 오늘의집 YYYY-MM-DD v0.png` … (최대 5장)
- `사례정리 YYYY-MM-DD.md` — 사례마다 원본 링크, 공간 유형, 색 조합, 주요 자재, 조명·수납 포인트, 우리 현장에 반영할 점
- `실행로그 YYYY-MM-DD v0.txt`

옵시디언 `Obsidian Vault\야간 작업\야간 작업 결과 목록.md` 맨 끝에 그날 사례정리 파일 링크가 한 줄씩 자동으로 쌓입니다.
캡처 이미지는 옵시디언에 넣지 않고 링크만 둡니다. (링크는 PC에서 클릭하면 열리고, 휴대폰에서는 적힌 위치를 드라이브 앱에서 찾으면 됩니다.)
- 로그인이 필요하거나 캡처를 막는 사이트는 건너뛰고 **링크만** 기록합니다.

## 지켜지는 규칙
- 기존 파일은 읽기만 합니다. 같은 날 다시 돌려도 `v1`, `v2` 새 파일로 저장되고 기존 파일은 그대로입니다.
- 지난 날짜 정리 문서에 있던 링크는 다시 캡처하지 않습니다(중복 제외).
- 캡처 이미지는 **내부 참고용**입니다. 제안서·홍보물에 그대로 쓰지 않습니다.
- 외부로 게시·발송하는 동작은 없습니다(검색·열람·캡처만).

## 알아둘 점
- 공간 유형·자재·조명·수납은 페이지 글의 키워드와 사진 색에서 **자동 추출**합니다. 담당자가 보고 다듬어 쓰세요.
- 핀터레스트는 로그인 없이 막히는 경우가 많아, 대부분 "링크만 기록"으로 남을 수 있습니다.
- PC가 **꺼져 있으면** 깨울 수 없습니다(절전만 가능). 꺼져 있던 날은 다음에 켜고 로그인할 때 실행됩니다.
- 노트북은 전원을 연결해 두는 것이 안전합니다(일부 모던 스탠바이 기종은 배터리 상태에서 깨우기를 무시).
- 검색어를 바꾸려면 스크립트 위쪽 `QUERIES` 목록을 고친 **새 버전 파일**(예: `… v1.py`)을 만들어 쓰세요.

## 수동 실행
```
python "디자인사례캡처 2026-10-31 v1.py" --root "G:\내 드라이브"
```
옵션: `--max 3`(건수), `--date 2026-11-01`(날짜 지정), `--sources 오늘의집 "인테리어 블로그"`(사이트 지정)
