# 지명원 작업 규칙

## 작업 위치
- 지명원 작업은 이 `jimyeongwon` 폴더에서만 한다. 홈페이지(`site/`)·인트라넷 파일과 섞지 않는다.

## 기준본
- 기준본은 「주식회사 홈퍼니싱 지명원 25.03.26.pdf」(드라이브 ID 162Itp4VqzFPgZOHsV2i37cWe80wJlreD) 하나뿐이다. 10.22 웹 ver-0이나 v1을 기준으로 쓰지 않는다.
- 기존 페이지는 한 글자도 바꾸지 않는다. 신규 페이지는 기존 시공사례 페이지와 같은 틀·글꼴·색으로 만든다.

## 옵시디언 저장 규칙
- 노트 위치: 구글 드라이브 'Obsidian Vault' > '지명원' 폴더 (ID 1bheEQUP55qmb64VHMMioHeHkWKHhNIZ3).
- 노트 2개를 유지한다.
  - '지명원 진행기록 날짜 v번호.md': 대화·지시·결정·결과를 날짜순으로.
  - '지명원 남은 일 날짜 v번호.md': 아직 안 끝난 것, 대표님이 직접 할 것.
- 파일 이름은 '제목 날짜 v번호'. 고칠 때마다 번호를 하나씩 올린 새 파일로 저장하고, 날짜는 그 버전을 만든 날짜로 쓴다. 이전 버전은 지우지 않는다.
- 이 작업을 할 때마다 진행기록을 새 버전으로 올린다 (남은 일이 바뀌면 남은 일 노트도).
- PDF·이미지 같은 실제 파일은 옮기지 않고 원래 위치에 둔 채 노트에 드라이브(또는 GitHub) 링크만 건다.
- 현장·사람·업체 이름에는 [[ ]] 링크를 건다 (예: [[구리역 롯데캐슬 시그니처]], [[주식회사 홈퍼니싱]]).
- 중요한 것은 **굵게** 또는 ==강조==. 이모지는 쓰지 않는다.
