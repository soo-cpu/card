# 본사 사옥 이전 (office-relocation)

주식회사 홈퍼니싱 본사 이전 (구리 인창동 → 서울, 2027년) 사무실 찾기 작업 폴더. 다른 작업 파일과 섞지 않는다.

- 찾는 지역: 성수동 / 광장동·구의동 / 청량리 일대
- 조건: 전용 30평 내외, 월세 300만 원 안팎(관리비 별도), 6~7명 + 상담 공간, 주차, 역·큰길 가까움
- 파일
  - `사옥 이전 비교 YYYY-MM-DD vN.md` — 지역 비교 (번호 이어서 올림)
  - `사옥 매물 YYYY-MM-DD.md` — 매일 아침 새 매물
  - `보고한 매물 목록.md` — 중복 제외용
- 같은 파일을 구글 드라이브 '본사 사옥 이전' 폴더에도 저장
- 확인 안 되는 정보는 '확인 필요'로 표시
