# 본사 사옥 이전 (office-relocation) 작업 규칙

이 폴더는 주식회사 홈퍼니싱 본사 이전(구리 인창동 → 서울, 2027년) 사무실 찾기 전용이다. 다른 작업 파일과 섞지 않는다.

## 찾는 조건
- 지역: 성수동 / 광장동·구의동 / 청량리 일대 / 8호선 라인 서울 구간 (암사·천호·강동구청·몽촌토성·잠실·석촌·송파·가락시장·문정·장지·복정, 11/1 추가)
- 전용 30평 내외(넘어도 됨), 층 상관없음, 월세 300만 원 안팎 기본 — 좋은 매물이면 500만 원까지 추천 (관리비 별도 표시)
- 직원 6~7명 + 상담 공간, 주차 편리, 역·큰길 가까움

## 저장 규칙
- 파일 이름은 '제목 날짜 v번호' (예: 사옥 후보 목록 2026-10-31 v0). 번호는 이어서 올린다. 예전 버전은 지우지 않는다.
- 확인 안 되는 정보는 '확인 필요'로 쓴다. 지어내지 않는다.
- 구글 드라이브 '본사 사옥 이전' 폴더 (ID 1cukHQc7UFtbmV2erSgi_Ri9XKbGe8K3q): 비교표, 매일 매물 파일(사옥 매물 YYYY-MM-DD .pdf/.md), 보고한 매물 목록.
- 옵시디언 보관함 'Obsidian Vault/사옥 구하기' 폴더 (드라이브 ID 1rCaY9KdV8L6efOBE0_LHMRqd7AFBE3ne):
  - '사옥 구하기 진행기록 날짜 vN.md' — 대화·작업을 날짜순으로
  - '사옥 후보 목록 날짜 vN.md' — 매물별 주소(동까지만), 가격, 면적, 장단점, 상태(검토·보류·제외)
  - '사옥 구하기 남은 일 날짜 vN.md'
  - **새 매물이 들어오면 후보 목록을 새 버전으로 저장한다** (이전 버전 내용 + 새 매물, 상태 갱신).
- 옵시디언 노트 규칙: 지역·건물·중개사 이름에 [[ ]] 링크(노트마다 첫 번째만), 중요한 건 **굵게** 또는 ==강조==, 이모지 쓰지 않는다. 맨 앞 > [!summary] 요약.
- 같은 파일을 저장소 office-relocation/obsidian/ 에도 둔다.
- 대표에게 보여줄 보고서는 PDF로 만들어 대화로 보낸다 (회사 양식, 매물마다 매물 원문·사진, 카카오맵 위치, 로드뷰, 네이버지도 버튼). 만드는 도구: tools/ (map.py, build.py, pdf.js).

## 매일 아침 예약 작업
- 이름 '본사 사옥 매물 아침 정리 (이 대화)', 매일 07:37 (한국시간). 2026-11-01부터 대표와 대화하는 같은 세션으로 들어온다 (대표가 결과를 대화에서 바로 보길 원함).
- 결과는 대화 답변 안에 매물별로 바로 보여주고, PDF는 대화로 보낸다. 드라이브·옵시디언 저장도 함께.

- 만드는 법: page/gen.py 의 목록을 고치고 python3 gen.py → index.html 을 같은 slug로 다시 publish.
- 매물마다 [매물 사진·원문 보기] [건물·주변 사진 검색] [로드뷰] [카카오맵] [네이버지도] 버튼. 아티팩트는 외부 사진을 직접 띄우지 못하고, 작업 환경도 사진 서버가 막혀 있어 사진은 버튼 링크로 연다.
- 새 매물이 들어오면 후보 목록 새 버전과 함께 이 보드도 갱신한다.
