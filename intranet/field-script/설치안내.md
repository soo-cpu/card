# 현장소통 서버 설치 (대표가 PC에서 한 번만, 약 5분)

화면: https://soo-cpu.github.io/card/field/ (GitHub Pages)
서버: 이 폴더의 `Code.gs` (Google Apps Script 웹앱)
데이터: 구글 드라이브 › `현장소통 (고객 현장 페이지)` 폴더
- `현장소통 데이터 2026-11-06 v0` (구글 시트 — 현장·글·댓글·사진·PDF·설정·기록 탭)
- `현장소통 사진·기록` › 현장별 폴더 › 월별 폴더(예: 2026-11) › 사진, 현장 폴더 바로 아래 PDF
- `현장소통 첫 비밀번호.txt` (설치 때 한 번 읽어 '설정' 탭에 옮김)

## 순서
1. 드라이브에서 `현장소통 데이터 2026-11-06 v0` 시트를 연다 → 메뉴 **확장 프로그램 › Apps Script**.
2. 편집기의 내용을 모두 지우고, `Code.gs` 전체를 붙여 넣고 저장(Ctrl+S).
   코드 원본: https://github.com/soo-cpu/card/blob/claude/company-intranet-draft-eoogkh/intranet/field-script/Code.gs (오른쪽 위 '복사' 버튼)
3. 위쪽 함수 목록에서 **setup** 고르고 **실행** → 권한 허용(‘고급’ → ‘이동’ → 허용).
   → 시트에 탭 7개가 생기고, 시험 현장(대표 확인용) 3일치 글·사진·댓글이 채워진다.
4. 오른쪽 위 **배포 › 새 배포** → 톱니 › **웹 앱** → 실행: **나** / 액세스 권한: **모든 사용자** → 배포 → **웹 앱 URL 복사**.
5. 클로드에게 "현장소통 서버 주소: (복사한 URL)" 이라고 보내면 `field/config.js`에 넣어 바로 반영한다.

- 4번에 '모든 사용자'가 없으면(회사 계정 제한): 같은 시트를 개인 지메일 계정에서 열어(편집 권한 공유) 1~4번을 다시 하면 된다.
- 코드를 고친 뒤에는 **배포 › 배포 관리 › 연필 › 버전: 새 버전 › 배포** (주소는 그대로).

## 관리 비밀번호 바꾸는 법
시트 **'설정' 탭 › '관리 비밀번호' 줄 B칸**을 고치면 바로 바뀐다. 10번 틀리면 15분 잠김.

## 지우지 않는 원칙
글·댓글은 '숨기기'만 있다(시트에 Y 표시, 행은 남음). 글을 고치면 고치기 전 내용이 '기록' 탭에 남는다.
