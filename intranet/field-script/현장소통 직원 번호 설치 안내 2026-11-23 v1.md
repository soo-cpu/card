# 현장소통 직원 번호 설치 안내 2026-11-23 v1

(이전 판: `현장소통 직원 번호 설치 안내 2026-11-23 v0` · 관련 판: `현장소통 직원 열쇠 설치 안내 2026-11-23 v2` — 둘 다 그대로 남겨 둠)

이번 판에서 바뀐 것 (검토 반영): 가짜 토큰을 여러 번 보내도 진짜 직원의 기억 기기는 막히거나 지워지지 않게 고침 · 잠시 오류·연결 끊김에는 기기 기억을 지우지 않음 · **퇴사 차단 때 임시 열쇠도 새로 만들기** 순서 추가.

대표 지시(2026-11-23): 현장소통 **관리 화면(?admin)** 을 직접 열 때 직원마다 **고정 6자리 번호**로 들어가게 합니다.
- 인트라넷은 지금처럼 구글 로그인. 인트라넷 '관리 화면 열기' 버튼으로 가면 지금처럼 번호 없이 바로 열려요.
- 그 버튼이 쓰는 5분짜리 1회용 입장권(스크립트 속성 `FIELD_STAFF_KEY`)은 지우지 않고 그대로 두고, 이제부터 이름만 **'임시 열쇠'** 라고 불러요 (외부 인원 등 예외용).
- **관리 비밀번호는 대표 전용** 그대로.

## 대표가 할 일 (Apps Script, 한 번만)

### 1. Code.gs 를 v5 로 바꿔 붙이기
1. 드라이브 **'현장소통 데이터 2026-11-06 v0'** 시트 → **확장 프로그램 › Apps Script**.
2. `Code.gs` 를 모두 지우고 저장소의 새 `Code.gs` (맨 위에 `현장소통 Code.gs 2026-11-23 v5`) 전체를 붙여 넣고 저장. (`Imagen.gs` 는 그대로)
3. 왼쪽 톱니(프로젝트 설정) › **'appsscript.json 매니페스트 파일을 편집기에 표시'** 를 켜고, `appsscript.json` 의 `oauthScopes` 에 아래 한 줄이 있는지 확인 (저장소 판에는 들어 있음 — 없으면 저장소 `appsscript.json` 내용으로 바꿔 붙임):
   `"https://www.googleapis.com/auth/script.send_mail"`

### 2. 스크립트 속성 두 개 (프로젝트 설정 › 스크립트 속성)
| 속성 | 값 | 없으면 |
|---|---|---|
| `OWNER_EMAIL` | 새 기기 알림을 받을 **대표 메일 주소** | 메일은 보내지 않고 '기록' 탭에만 남김 |
| `PIN_SALT` | **직접 넣지 않아도 됨** — 3번 setup 이 무작위로 만듦 | 번호 입장이 "준비되지 않았어요"로 막힘 |

- 메일 주소는 코드·저장소에 쓰지 않고 이 속성에만 둡니다.
- `PIN_SALT` 는 **한 번 생기면 바꾸거나 지우지 마세요.** 바꾸면 모든 직원 번호와 기억 기기가 맞지 않게 되어 번호를 새로 정해야 해요.

### 3. setup 한 번 실행 ▶
- 편집기 위 함수 목록에서 `setup` 을 고르고 ▶ 실행.
- **권한 허용 창**이 뜨면: 계정 선택 → '고급' → '(안전하지 않음)으로 이동' → **허용**. 이번에는 **'내 이름으로 이메일 보내기'(MailApp)** 권한이 새로 추가돼요.
- 하는 일: 새 탭 **'직원 번호'**(이름·번호 해시·상태·틀린 횟수·바꾼 때·세대·잠긴 때), **'기억 기기'**(직원·토큰 해시·만든 때·만료·기기 요약·상태·마지막 사용) 만들기, '설정' 탭에 **'직원 이름'** 줄(정진혁,이봄이,채진아) 넣기, `PIN_SALT` 만들기.
- 여러 번 실행해도 기존 행·칸·소금은 그대로입니다 (지우는 것 없음).

### 4. 새 버전 배포
- 오른쪽 위 **배포 › 배포 관리 › 연필 › 버전: 새 버전 › 배포** (주소는 그대로).
- 확인: 웹 앱 주소를 브라우저에 열면 `"v":5`.

### 5. 직원 번호 정하기 (현장소통 관리 화면)
1. 현장소통 관리 화면(`…/field/?admin`)을 열고 **관리 비밀번호**로 들어감.
2. 위 줄 **'직원 번호'** → 직원마다 **'번호 정하기'** → 6자리를 두 번 넣고 저장.
   - 같은 숫자(111111)·이어지는 숫자(123456 등)는 안 받아요. 번호는 화면에 다시 보이지 않으니 **직원에게 직접(말로) 알려 주세요.**
3. 같은 칸에서: **번호 바꾸기**(그 직원의 기억 기기·열린 출입증 모두 끝) · **잠금 풀기**(5번 틀려 잠긴 직원) · **즉시 차단 (퇴사)**(번호·기억 기기·이 이름 출입증 끊김, 다시 쓰려면 새 번호) · **직원 이름 추가** · **접속 기록**(빨간 '새 기기' 표시).
   - **퇴사 차단 때는 꼭 하나 더:** 인트라넷 **서식 자료실 › 현장소통 연결**에서 **직원 열쇠(임시 열쇠)를 새로 만들어** Apps Script **스크립트 속성 `FIELD_STAFF_KEY`** 를 새 값으로 바꾸고 저장하세요. (차단은 그 이름으로 온 입장권만 막아요. 열쇠를 바꾸면 옛 열쇠로 만든 입장권이 모두 끝나요)
   - 이름 목록은 시트 '설정' 탭 **'직원 이름'** 줄(쉼표로 구분)을 직접 고쳐도 됩니다. 고친 옛 값은 '옛 값' 탭에 남아요.
4. 이 칸은 **관리 비밀번호로 들어왔을 때만** 보이고, 서버도 직원 번호·임시 열쇠로 온 요청은 거절해요.

### 6. 현장소통 화면 올리기 (클로드가 함)
- `field/index.html` (현장소통 2026-11-23 v3) 이 main 에 합쳐져야 실제 주소에 반영됩니다. reviewer 통과 뒤 메인 세션이 올려요.
- 순서: 1~4번(서버) 먼저 → 화면. 화면만 먼저 올라가면 '직원 번호로 들어가기'가 "서버가 옛 버전이에요 (Code.gs v5 배포 필요)"라고 안내하고, 비밀번호·임시 열쇠는 그대로 돼요.

## 직원 사용법 (세 줄)
1. 휴대폰에서 현장소통 관리 화면 주소를 열고 **'직원 번호로 들어가기'** → **내 이름** 큰 버튼을 누른다.
2. 대표에게 받은 **6자리 번호**를 키패드로 누른다 (6자리가 되면 바로 들어감). 그 기기는 **30일 동안 번호 없이** 열린다.
3. 휴대폰을 바꾸면 번호를 다시 넣으면 되고(대표에게 알림이 감), 5번 틀리면 잠기니 **대표에게 풀어 달라고** 한다. 공용 기기에서는 다 쓰고 **'나가기'** (기억도 지워짐).

## 알아 둘 것 (보안)
- 번호는 서버에 **HMAC-SHA256(소금, 이름+번호) 해시만** 저장. 기억 기기 토큰도 해시만 저장하고, 토큰 자체는 그 기기의 localStorage 에만 있어요. 번호는 주소(?·#)·기기 저장소·기록·메일 어디에도 남지 않아요.
- 5번 틀리면 그 직원 **잠김** (시간이 지나도 안 풀림 → 대표가 풀어 줌). 모든 이름을 합쳐 1시간에 20번 틀리면 번호 입장이 1시간 막혀요 (기억 기기는 그대로 들어옴).
- 기억 기기는 서버가 "확실히 무효"(기억되어 있지 않음·만료·차단·번호 바뀜)라고 할 때만 그 기기에서 지워져요. 잠시 오류·연결 끊김에는 그대로 남아 다음에 다시 번호 없이 들어와요. 없는 토큰을 아무리 보내도 진짜 기기는 막히지 않아요 (토큰은 짐작할 수 없는 64자리).
- 새 기기 메일에는 **이름·시각·기기 요약(예: 아이폰 · 사파리)** 만 들어가요. 모르는 접속이면 '직원 번호 › 즉시 차단'.
- 지우는 행·칸 없음: 기억 기기는 상태만 '무효(번호 바뀜)'·'무효(차단)'·'만료'로 바뀌고, 바꾸기 전 상태는 '옛 값' 탭, 모든 입장·틀림·잠금·차단은 '기록' 탭.
- 고객 화면(확인 번호 4자리)·인트라넷 '고객 공유 페이지 열기'는 바뀐 것 없어요.
