# 현장소통 직원 열쇠 설치 안내 2026-11-19 v0

직원([[정진혁]]·[[이봄이]]·[[채진아]])이 인트라넷 프로젝트 화면에서 **'관리 화면 열기'** 를 누르면, 관리 비밀번호 없이 현장소통 관리 화면으로 들어가게 하는 설치예요. 대표 [[최윤수]]가 PC에서 한 번만 하면 됩니다 (약 10분).

- 관리 비밀번호는 바뀌지 않아요. 지금 비밀번호로 들어가는 방식도 그대로 됩니다.
- '직원 열쇠'는 관리 비밀번호와 **다른 값**이에요. 이 문서·코드·기록 어디에도 열쇠 값은 적지 않습니다.
- 아래 1~4번을 다 하기 전에는 직원 버튼이 예전처럼 **비밀번호 화면**으로 열립니다 (막히지 않아요).

## 순서

### 1. 인트라넷에서 열쇠 만들기 (인트라넷 v0.99-40 배포 뒤)
1. 인트라넷 왼쪽 메뉴 **서식 자료실** → **'현장소통 연결 (대표만)'** 을 펼친다.
2. **'직원 열쇠 만들기'** 를 누른다 → 긴 글자(43자)가 한 번 보인다.
3. **'복사'** 를 누른다. (나중에 다시 복사하려면 같은 자리의 '복사' 버튼)

### 2. Apps Script 에 열쇠 넣기
1. 드라이브에서 **'현장소통 데이터 2026-11-06 v0'** 시트를 연다 → 메뉴 **확장 프로그램 › Apps Script**.
2. 왼쪽 **톱니(프로젝트 설정)** → 맨 아래 **스크립트 속성 › 스크립트 속성 추가**.
3. 속성 이름: `FIELD_STAFF_KEY` / 값: 방금 복사한 열쇠를 **붙여 넣기** → **스크립트 속성 저장**.

### 3. 새 Code.gs 붙여 넣고 배포
1. 왼쪽 **편집기(< >)** → `Code.gs` 를 연다. (`Imagen.gs` 는 그대로 둔다)
2. 내용을 모두 지우고, 저장소의 새 `Code.gs` (v2) 전체를 붙여 넣고 저장(Ctrl+S).
   코드 원본: https://github.com/soo-cpu/card/blob/claude/company-intranet-draft-eoogkh/intranet/field-script/Code.gs (오른쪽 위 '복사' 버튼)
3. 오른쪽 위 **배포 › 배포 관리 › 연필 › 버전: 새 버전 › 배포**. (주소는 그대로)
4. 확인: 웹 앱 주소를 브라우저에 그대로 열면 `"v":2` 가 보인다.

### 4. 현장소통 화면 올리기 (클로드가 함)
- `field/index.html` 새 판이 **main 에 합쳐져야** 실제 주소(https://soo-cpu.github.io/card/field/)에 반영돼요. 클로드에게 "현장소통 화면 main 에 올려줘"라고 하면 됩니다.
- 순서는 3번(서버) 먼저, 4번(화면) 나중이 안전해요. 화면만 먼저 올라가도 고객 화면·비밀번호 로그인은 그대로 됩니다.

### 5. 확인
- [[정진혁]] 계정으로 인트라넷 프로젝트 → **'관리 화면 열기'** → 비밀번호를 묻지 않고 관리 화면이 열리면 끝.
- 자세한 점검: `intranet/tools/test/실제 화면 점검표 2026-11-19 v7.md` K 65~71번.

## 알아 둘 것
- 입장권은 **5분** 안에 한 번만 쓸 수 있고, 들어간 뒤에는 그 탭에서 **6시간** 동안 열려 있어요. 시간이 지나면 인트라넷에서 다시 누르면 됩니다.
- 누가 들어왔는지는 시트 '기록' 탭 '누가' 칸에 직원 이름으로 남아요.
- 직원이 퇴사하면: 인트라넷 공유에서 빼고, **'직원 열쇠 새로 만들기'** → 2번(속성 값 바꾸기)을 다시 하세요. 옛 열쇠는 그때부터 쓸 수 없어요 (인트라넷에는 기록으로만 남음).
- 열쇠를 새로 만들었는데 2번을 안 하면, 직원 버튼은 비밀번호 화면으로 열립니다.
- 안 될 때: 속성 이름이 정확히 `FIELD_STAFF_KEY` 인지, 값 앞뒤에 빈칸이 없는지, 3번에서 '새 버전'으로 배포했는지 확인.
