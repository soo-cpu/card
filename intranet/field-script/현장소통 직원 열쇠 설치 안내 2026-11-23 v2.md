고객 공유 페이지 자동 연결 (다음 지시 2026-11-23 v4 · B, 인트라넷 v0.99-46): 계약 단계부터 프로젝트 화면 **'고객 공유 페이지 열기'** 한 번 → 현장소통이 프로젝트 번호로 현장을 찾고, 없으면 **자동으로 만들고**, 있으면 그 현장을 바로 엽니다. 인트라넷 공정표 날짜도 누를 때마다 고객 공정표에 맞춰져요.

## 대표가 할 일

### 1. Code.gs 를 v4 로 바꿔 붙이고 새 버전 배포 (v3 를 이미 배포했으면 이것만)
1. 드라이브 **'현장소통 데이터 2026-11-06 v0'** 시트 → 메뉴 **확장 프로그램 › Apps Script**.
2. `Code.gs` 내용을 모두 지우고, 저장소의 새 `Code.gs` (맨 위에 `현장소통 Code.gs 2026-11-23 v4`) 전체를 붙여 넣고 저장(Ctrl+S). (`Imagen.gs` 는 그대로)
   코드 원본: https://github.com/soo-cpu/card/blob/claude/company-intranet-draft-eoogkh/intranet/field-script/Code.gs (오른쪽 위 '복사' 버튼)
3. **`setup` 은 다시 실행하지 않아도 돼요.** v3 때 실행해서 '옛 값' 탭·'고객 이름' 칸이 이미 있어요. (v3 때 setup 을 건너뛰었다면 한 번 실행 ▶ — 여러 번 해도 기존 행·칸은 그대로, 지우는 것 없음. 그리고 setup 을 안 해도 새 칸·탭은 처음 쓸 때 저절로 생겨요)
4. 오른쪽 위 **배포 › 배포 관리 › 연필 › 버전: 새 버전 › 배포**. (주소는 그대로)
5. 확인: 웹 앱 주소를 브라우저에 그대로 열면 `"v":4` 가 보인다.

### 2. 직원 열쇠 (아직 안 했으면만)
- 인트라넷 **서식 자료실 › 현장소통 연결 (대표만)** → '직원 열쇠 만들기' → 복사 → Apps Script **프로젝트 설정(톱니) › 스크립트 속성 › `FIELD_STAFF_KEY`** 에 붙여 넣고 저장. (자세한 순서는 v0 판)
- 열쇠가 없어도 버튼은 동작해요: 비밀번호 화면이 한 번 나오고, 비밀번호를 넣으면 이어서 자동으로 찾기/만들기를 해요.

### 3. 현장소통 화면 올리기 (클로드가 함)
- `field/index.html` (현장소통 2026-11-23 v2 · v3·v4 서버 둘 다 받아 줌) 이 **main** 에 합쳐져야 실제 주소에 반영돼요. reviewer 통과 뒤 메인 세션이 올립니다.
- 순서: 1번(서버) 먼저 → 3번(화면). 화면만 먼저 올라가면 '고객 공유 페이지 열기'가 "서버가 옛 버전이에요" 안내 뒤 현장 목록으로 열려요 (막히지 않음).

## 직원 사용법 (세 줄)
1. 프로젝트 화면(계약 단계부터) **'현장 진행 상황' 칸 › '고객 공유 페이지 열기'** 를 누른다 → 처음이면 현장이 자동으로 생기고 **고객 주소 창**이 뜬다.
2. 그 창에서 **'카톡용 안내문 복사'** 로 고객에게 보낸다. 고객은 휴대폰 뒷번호 4자리로 연다. (주소를 인트라넷 '고객 공유 페이지 코드' 칸에 넣어 두면 프로젝트 화면에서도 **'고객 주소 복사'** 가 생김)
3. 공정표를 고쳤으면 다시 **'고객 공유 페이지 열기'** 만 누르면 고객 공정표 날짜가 맞춰진다. 현장소통 현장 목록 위 **검색 칸**에 고객 이름·현장명·전화 뒷번호를 넣으면 바로 찾는다.

## 알아 둘 것
- 주소에 붙는 값(현장명·고객 이름·고객 휴대폰 **뒷 4자리**·담당·착공/준공·공정표 날짜)은 주소 맨 뒤 **# 뒤**에만 잠깐 붙고, 현장소통이 읽자마자 지워요 (방문 기록·서버 주소에 안 남음). 원가·마진·금액·고객 전체 전화번호·비밀번호·열쇠는 넣지 않아요.
- 같은 프로젝트 번호로는 현장이 **한 번만** 생겨요 (동시에 눌러도). 숨긴 현장은 찾지 않아요.
- 공정 날짜를 맞출 때 바꾸기 전 공정은 시트 **'옛 값'** 탭에 통째로 남아요. 같은 이름 단계의 진행 상태(대기·진행 중·완료)는 그대로 이어지고, 공정표에 없는 단계라도 진행 중·완료였던 것은 남겨요.
- 고객 화면에는 고객 이름·확인 번호·프로젝트 번호가 나가지 않아요 (관리 화면·검색에만). 인트라넷 현장명이 비어 있으면 현장명이 '홈퍼니싱 현장'으로 만들어지니, 필요하면 '현장 정보'에서 고쳐 주세요.
- 계약 전 프로젝트는 지금처럼 **'고객 공유 페이지 만들기'** (현장 추가 창 미리 채움). 현장소통 **'+ 현장 추가'** 는 예외용으로 그대로 있어요.
