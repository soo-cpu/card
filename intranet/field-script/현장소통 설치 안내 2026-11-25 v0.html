A. APPS SCRIPT (대표 계정 PC 권장)

Apps Script 열기

  2. 메뉴 확장 프로그램 › Apps Script를 누릅니다.
2

열쇠·알림 메일 붙이기 (스크립트 속성)

  1. 인트라넷 서식 자료실 › 현장소통 연결에서 직원 열쇠 만들기(이미 있으면 새로 만들기) → 열쇠 복사.
  2. Apps Script 왼쪽 톱니(프로젝트 설정) › 맨 아래 스크립트 속성 › 스크립트 속성 추가.
  3. 속성 FIELD_STAFF_KEY · 값 = 방금 복사한 열쇠 (이미 있으면 값만 바꿈).
  4. 속성 OWNER_EMAIL · 값 = 새 기기 알림을 받을 대표님 메일.
  5. 스크립트 속성 저장.

PIN_SALT는 직접 넣지 마세요. 4번 setup 때 저절로 생기고, 한 번 생기면 바꾸거나 지우면 안 돼요.

3

Code.gs 바꾸고 메일 권한 넣기

  1. 왼쪽 Code.gs를 열고 안의 글을 전부 지운 뒤 아래 v5 코드를 붙여 넣고 저장(디스크 모양). Imagen.gs는 그대로 둡니다.
  2. 톱니(프로젝트 설정)에서 ‘편집기에서 appsscript.json 매니페스트 파일 표시’를 켭니다.
  3. 왼쪽에 생긴 appsscript.json을 열고 전부 지운 뒤 아래 내용을 붙여 넣고 저장.

복사가 막히면 칸을 길게 눌러 ‘전체 선택 → 복사’ 하세요. 같은 코드가 드라이브 인트라넷 폴더 ‘현장소통 Code.gs 2026-11-23 v5.txt’에도 있어요.

4

setup 한 번 실행

  1. 위쪽 함수 고르는 칸에서 setup을 고르고 ▶ 실행.
  2. ‘권한 검토’ 창이 뜨면 대표 계정 → 고급 › (안전하지 않음)으로 이동 › 허용. 메일 보내기 권한이 새로 들어 있어요.
  3. 아래 실행 로그에 오류가 없으면 끝. 스크립트 속성에 PIN_SALT가 생겼는지 한 번 봅니다.

기존 현장·글·사진 행은 그대로예요. 새 탭(‘직원 번호’, ‘기억 기기’, ‘옛 값’)과 새 칸 머리글만 생겨요.

5

같은 주소로 새 버전 배포

  1. 오른쪽 위 배포 › 배포 관리.
  2. 지금 쓰는 웹 앱 줄의 연필(수정) → 버전 칸에서 새 버전 → 배포.
  3. 웹 앱 주소를 열어 "v":5가 보이면 성공.

‘새 배포’를 누르지 마세요. 새 배포는 주소가 바뀌어 현장소통 화면이 서버를 못 찾아요. 꼭 ‘배포 관리 › 연필 › 새 버전’.

6

관리 비밀번호를 대표님만 아는 값으로

  1. 현장소통 데이터 시트의 설정 탭을 엽니다.
  2. 관리 비밀번호 줄의 값 칸을 새 비밀번호로 바꿉니다 (12자 이상, 다른 곳에 안 쓰는 값). 바꾸는 즉시 적용돼요.
  3. 새 비밀번호는 직원·카톡·메일에 보내지 마세요. 직원은 열쇠(인트라넷 버튼)나 6자리 번호로 들어가요.

이 시트는 대표님 계정만 편집할 수 있게 공유를 그대로 두세요. 드라이브의 ‘현장소통 첫 비밀번호.txt’는 처음 설치 때만 쓰였고 지금은 안 읽어요.

B. 첫 현장 · 직원 확인

8

직원 번호 정하기

  1. soo-cpu.github.io/card/field/?admin을 열고 대표 전용 · 관리 비밀번호로 들어갑니다.
  2. 직원 번호 칸에서 정진혁·이봄이·채진아에게 각각 6자리를 정합니다 (생일·전화번호 끝자리·111111 같은 쉬운 번호는 피하기).
  3. 번호는 직원에게 직접 말로 알려 주세요. 화면에 다시 보이지 않아요.
9

김정래 현장을 첫 현장으로

  1. 인트라넷(대표 화면) 프로젝트에서 김정래 (아름마을 LG) 프로젝트를 엽니다.
  2. 단계가 계약·시공인지 봅니다 (상담·디자인·견적이면 ‘고객 공유 페이지 만들기’ 버튼이 나와요 — 그때는 Claude에게 알려 주세요).
  3. 담당이 정진혁인지 봅니다 (10번 확인에 필요).
  4. ‘현장 진행 상황’ 칸 고객 공유 페이지 열기 → 새 탭에서 현장이 저절로 생기고 고객 주소 창이 떠요.
  5. 창의 주소만 복사 → 인트라넷 김정래 프로젝트 고객 공유 페이지 코드 칸에 붙여 넣고 저장 → 프로젝트 화면에 ‘고객 주소 복사’가 생겨요.
  6. 현장소통에서 공정 날짜가 프로젝트 공정표와 같은지, 현장명이 맞는지 봅니다.

다시 ‘고객 공유 페이지 열기’를 눌러도 같은 현장이 열려요. 공정표를 고친 뒤 누르면 날짜가 맞춰지고, 바뀌기 전 값은 시트 ‘옛 값’ 탭에 남아요.

10

정진혁 계정으로 열리는지 확인

  1. 정진혁 실장 휴대폰에서 인트라넷 → 김정래 프로젝트 → 고객 공유 페이지 열기 → 비밀번호 없이 같은 현장 관리 화면이 열리면 OK.
  2. 같은 휴대폰에서 soo-cpu.github.io/card/field/?admin 직접 열기 → 직원 번호로 들어가기 → ‘정진혁’ → 6자리 → 열리면 OK. 대표님 메일로 새 기기 알림이 오는지 봅니다.
  3. 한 번 더 열어 번호를 다시 묻지 않으면 30일 기억 OK.
  4. 현장소통 시트 기록 탭의 ‘누가’ 칸에 정진혁이 찍혔는지 봅니다.
  5. 마지막으로 고객 주소를 다른 휴대폰에서 열어 휴대폰 뒷번호 4자리로 열리고, 고객 이름·프로젝트 번호·금액이 안 보이는지 봅니다.

안 되는 곳이 있으면 몇 번 단계인지와 화면에 나온 글을 Claude에게 보내 주세요.
