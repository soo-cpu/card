# 실제 화면 점검표 2026-11-14 v3

(v2 2026-11-14 를 이어서 고친 판 · v0·v1·v2 파일은 그대로 둠 · 이번에 바뀐 곳: G 27~33번 문자 6종 자동 채움 (v0.99-34) · 앞 판에서 바뀐 곳: F 24번 공정표 확인 창, A1 전화번호 필수, B 11번)

대표 [[최윤수]]가 claude.ai 인트라넷(https://claude.ai/artifact/YKp7VvPpkG9aVuWQLsFCJY, 지금 **v0.89**)에서 직접 눌러 보는 순서. 한 줄씩 해 보고 체크. 안 되면 오른쪽 아래 '불편해요 / 고쳐주세요'에 화면 캡처와 함께 남기기.
시험은 이름에 **'시험'**을 넣은 프로젝트로 해서 실제 고객 카드와 섞이지 않게.

## A. 프로젝트 → 견적 → 저장 → 되돌리기 → 삭제 → 복구 (대표 계정)
- [ ] 1. 왼쪽 메뉴 '프로젝트' → '문의 접수 (새 프로젝트)' → 고객명 '시험 점검'과 전화번호(예: 010-0000-0000 · 지금은 꼭 넣어야 저장돼요) 넣고 저장 → 번호 P-2611-00N이 붙고 고객 카드도 같이 생긴다
- [ ] 2. 같은 고객명·같은 주소로 한 번 더 만들어 본다 → "이미 있는 프로젝트예요" 창과 '기존 프로젝트 열기'가 뜬다 (확인 후 닫기)
- [ ] 3. 시험 프로젝트를 열어 단계 바에서 '견적'을 누른다 → 견적서가 바로 열리고 첫 화면이 '상세 견적(공종별)'이다
- [ ] 4. 아무 품목 수량을 넣는다 (예: 주방 하부장 3) → 금액·부가세 포함 합계가 자동으로 바뀐다
- [ ] 5. 저장 → 화면 위에 저장 완료가 크게 뜨고, 견적 관리 목록에 1차가 생긴다
- [ ] 6. 프로젝트로 돌아가 '◀ 이전 단계로'를 누른다 → 확인 창 뒤 한 단계 되돌아간다
- [ ] 7. 프로젝트 목록 맨 왼쪽 체크칸으로 시험 프로젝트를 고르고 '선택 삭제' → 확인 창 한 번 → 목록에서 사라진다 (편집 창이 다시 열리면 안 됨)
- [ ] 8. 왼쪽 메뉴 '휴지통 (관리자)' → 시험 프로젝트·같이 옮겨진 견적이 보인다 (**'비어 있음'이 나오면 실패**)
- [ ] 9. 체크 후 '선택한 것 되살리기' → 프로젝트·견적이 같이 돌아온다
- [ ] 10. 다시 지울 때는 상세 창 아래 '삭제' → 휴지통 (점검 끝)

- [ ] 12. [[정진혁]] 실장: 프로젝트·상담·견적·현장·고객·'현장 자료 (드라이브)'가 보인다 / 재무·경영·경리·인사 자료함은 **안 보인다** / 인사는 본인 것만 / 전자결재는 본인 것만
