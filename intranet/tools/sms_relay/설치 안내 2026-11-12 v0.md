# 문자 중계 설치 안내 2026-11-12 v0

인트라넷에서 누른 문자를 **대표 PC**가 알리고로 대신 보내 주는 작은 프로그램입니다. 한 번만 설치하면 됩니다.

## 설치 (5단계)
1. 이 폴더(`sms_relay`)를 대표 PC의 아무 곳(예: `C:\홈퍼니싱\sms_relay`)에 복사합니다. **구글 드라이브 안에는 두지 마세요** (알리고 키가 들어가기 때문).
2. `env 예시.txt`를 같은 폴더에 `.env` 이름으로 복사하고, 알리고 **API 키 · 아이디 · 발신번호**를 적습니다. `SMS_QUEUE=` 뒤에는 PC에 보이는 드라이브의 **'문자 발송함' 폴더 경로**를 적습니다 (예: `G:\내 드라이브\...\문자 발송함`).
3. 알리고 사이트 > 문자 API > **발송 서버 IP**에 대표 PC의 인터넷 IP를 등록합니다. (IP 확인: 네이버에서 '내 IP' 검색)
4. 폴더에서 주소창에 `powershell`을 입력해 창을 열고 아래 한 줄을 실행합니다.
   `powershell -NoProfile -ExecutionPolicy Bypass -File install_relay.ps1`
5. 인트라넷 고객 카드에서 **시험 발송**으로 한 번 보내 봅니다. 1~2분 뒤 고객 카드 '문자 기록'이 **시험 성공**으로 바뀌면 끝입니다.

## 실제로 보내기 시작할 때
- 처음에는 `.env`에 `SMS_FORCE_TEST=Y`가 있어 **어떤 문자도 실제로 나가지 않습니다.**
- 먼저 `SMS_FORCE_TEST=N`, `SMS_ONLY_TO=대표 휴대폰 번호`로 바꿔 대표 번호로만 실제 문자를 받아 봅니다.
- 잘 오면 `SMS_ONLY_TO=`를 비웁니다. 이때부터 고객에게 실제로 나갑니다.

## 알아 둘 것
- PC가 **켜져 있고 로그인해 있는 동안**에만 문자가 나갑니다. 꺼져 있을 때 누른 문자는 PC를 켜면 나가고, **24시간이 지난 것은 보내지 않습니다.**
- 하루 실제 발송은 200건까지 (`SMS_DAILY_MAX`), 한 번에 50명까지입니다.
- 기록은 `sms_relay_state\sms_relay.log`에 남습니다 (전화번호는 뒤 4자리만, 키는 남지 않음).
- 1분마다 검은 창이 잠깐 깜빡일 수 있습니다.
- 그만 쓰려면: `powershell -NoProfile -ExecutionPolicy Bypass -File install_relay.ps1 -Remove`
