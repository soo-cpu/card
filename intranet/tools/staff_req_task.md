## 순서
1. 개선 요청함에서 상태가 `접수`(또는 비어 있음)인 요청을 읽는다. 작성자 이름은 직원 명단(staff.uid)으로 찾는다.
2. 간단 수정은 고치기 전에 지금 인트라넷 HTML을 백업한다 (스크래치 + 드라이브 '버전 보관'은 대표 화면이 자동 저장). 테스트 화면에서 그 직원 권한으로 확인한 뒤 배포.
   - 다른 세션이 먼저 배포했으면 그 버전 위에 합쳐서 배포 (덮어쓰지 않기).
3. 요청 문서에 `reply`, `status`, `updatedAt`, `updatedBy:"claude"`를 쓰고, 형 확인 필요 건은 `bossCheck`(이유)도 쓴다.
4. 목록 파일을 새 버전으로 저장 (번호 / 작성자 / 화면 / 요청 내용 / 분류·상태 / 처리 내용 또는 이유 / 알림 보냄).
5. 알림: **형 확인 필요 건이 새로 생겼을 때만**.
   - 제목: `[인트라넷 요청] 확인 필요 N건 - YYYY-MM-DD HH:MM`
   - 본문: 번호 / 작성자 / 화면 / 요청 내용 / 확인이 필요한 이유 또는 실패 이유
   - 받는 곳: 대표 구글 계정 Gmail. Gmail 연결이 없으면 휴대폰 알림(PushNotification) + 목록 파일로 대신하고 진행 기록에 적는다.
   - 같은 건은 다시 보내지 않는다: 보낸 요청 문서에 `notifiedAt`을 쓰고, 이미 있으면 건너뛴다.
6. 처리한 게 있으면 `intranet/진행기록.md`에 한 줄 + 커밋·푸시, 옵시디언 대화 기록. 아무것도 없으면 "새 요청 없음" 한 줄로 끝낸다.

## 7. 물어보기 질문 처리 (대표 지시 2026-11-06, v0.86)
- 직원별 `acct/<직원 uid>/askq` 문서 중 status가 '대기'인 것: 인트라넷 사용법·접속 문제면 답을 `a`에 쓰고 status '답함', answeredAt, answeredBy:'예약 작업'으로 update(if_version). 직원은 물어보기 창에서 답을 봄.
- 답할 수 없거나 권한·데이터 변경·돈 관련이면 status '대표 전달'로 바꾼다 (대표 빨간 불에 뜸). 새로 '대표 전달'이 생기면 4번처럼 알림 1회 (같은 건 중복 금지, notifiedAt).
- 직원 uid 목록은 `staff` 컬렉션의 uid. 질문 내용에 주민번호·계좌번호가 있으면 답에 옮기지 않는다.
