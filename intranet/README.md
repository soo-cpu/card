# 홈퍼니싱 인트라넷 (초안 v0.2)

직원 공유용 인트라넷. 실제로 쓰는 곳은 claude.ai 인트라넷 링크(공유 DB·로그인 이름·파일 첨부)입니다.
이 폴더의 `index.html`은 원본 소스이고, GitHub Pages로 열면 **연습 모드**(이 브라우저에만 저장)로 동작합니다.

## 메뉴
- 전자결재: 공유드라이브 「0. 홈퍼니싱」 본사 서식 기준 24종 (비용·지급 / 현장·공사 / 계약·총무 / 인사·근태), 결재선 담당 → 검토 → 최종
- 업무 매뉴얼, 현장 관리(현장일보·사진·폴더 링크), 고객 관리(고객관리 툴 v3.2의 24단계), 견적 관리(상담견적 v.15 상태 흐름·견적 대장), 사후 관리(A/S)
- 인사 관리: 직원 명부 + 인사기록카드(본사 인사기록부 양식, 대표·편집자만), 승인된 휴가신청서로 연차 자동 집계
- 서식 자료실: 본사 서식 원본 링크 (원본은 수정하지 않음)

## 보안
- 고객: 성만, 연락처 뒤 4자리. 계좌번호·주민번호는 적지 않고 첨부로만.
- 원가·마진은 상담견적 툴에만 둠.
