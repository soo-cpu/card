## 1. 새 파일 붙여넣기

1. **soo@artico-studio.com** 으로 https://script.google.com 접속
2. **간편견적** 프로젝트 열기 (손님 간편견적 화면을 띄우는 스크립트, 코드 첫 줄이 `// 간편견적 — 고객 화면 배포…`)

4. 안에 있는 글을 지우고 `sian_intranet.gs` 내용을 **통째로** 붙여넣기 → **저장(디스크 모양)**

> 기존 `Code.gs`(또는 원래 파일)는 **지우거나 바꾸지 않습니다.** 아래 두 줄만 더합니다.

## 2. 기존 코드에 한 줄씩 (두 곳)

**① `function doGet(e) {` 바로 아래**, `const p = …` 줄 **다음 줄**에:

```js
  if (p.a === 'isian') return isianDoGet_(e);
```

**② `function doPost(e) {` 안**, `d = JSON.parse(…);` 줄 **바로 다음 줄**에:

```js
    if (d.action === 'isian') return isianJson_(isianRun_(d));
```

→ **저장**.

## 3. 토큰 IMG_TOKEN 만들기

1. 왼쪽 **톱니바퀴(프로젝트 설정)** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
2. 속성: `IMG_TOKEN`
3. 값: **아무 긴 글자 40자 이상** (영어·숫자 섞어서. 예: 키보드로 아무렇게나 쳐도 됨)
   - 이 값은 **메모장에 잠깐 복사**해 두고, 5번에서 인트라넷에 넣은 뒤 지웁니다.
   - 카톡·메일·문서에 **남기지 마세요.**
4. **스크립트 속성 저장**

선택 (안 넣으면 기본값):

| 속성 | 뜻 | 기본 |
|---|---|---|
| `ISIAN_DAY_MAX` | 인트라넷 전체 하루 장수 | 30 |
| `ISIAN_PROJ_MAX` | 프로젝트 하나 하루 장수 | 10 |
| `ISIAN_USER_MAX` | 직원 한 명 하루 장수 | 15 |
| `ISIAN_MODEL` | 모델 고정 (비우면 손님 시안과 같은 자동 선택) | 비움 |

> 손님 시안 한도(기기 2장·전체 30장)와 **따로** 셉니다. 실패한 장은 세지 않습니다.

## 5. 인트라넷 설정

1. 인트라넷(대표 계정) → 메뉴 **이미지 생성** → 맨 위 **시안 이미지 (대표 전용)** 카드
2. **만드는 방식**: `간편견적 Gemini (인트라넷 시안)`
3. **간편견적 Apps Script 주소**: 배포 관리에 보이는 웹 앱 URL (`https://script.google.com/macros/s/…/exec`, 손님 화면과 같은 주소)
4. **간편견적 IMG_TOKEN**: 3번에서 만든 값 붙여넣기
5. **저장** → 메모장에 복사해 둔 토큰은 지우기

- 토큰은 **대표 전용 칸**에만 저장됩니다. 직원 화면·공용 칸에는 안 내려갑니다.
- 직원은 토큰 대신 **그날만 쓰는 입장권**을 받습니다. 대표 화면이 열릴 때 7일치를 자동으로 넣습니다.
  (대표 화면을 일주일 넘게 안 열면 직원은 "오늘 입장권이 아직 없어요"가 뜹니다 → 대표 화면을 한 번 열면 됩니다.)

## 6. 시험 (1장)

1. 인트라넷 → 프로젝트 하나 열기 → **진행 상황** 탭 → **시안 이미지 만들기** 펼치기
2. 현장 사진 1장 누르기 (또는 **새로 올리기**로 도면·사진) → 누른 사진 아래 `도면 / 현장 사진` 확인
3. 스타일·공간·요청 고르기 → **① 준비하기** → **② 생성 (새 탭)**
4. 새 탭에서 30초쯤 기다리면 시안이 보입니다 → 탭 닫기
5. 인트라넷으로 돌아와 **③ 결과 불러오기** → 시안이 프로젝트에 붙으면 성공
6. 드라이브 현장 폴더 › `P-…` › **시안 이미지** 에 `시안 P-YYMM-NNN YYYY-MM-DD v0.png` 가 있는지 확인

실패하면 새 탭에 **이유**가 나옵니다:

| 보이는 말 | 할 일 |
|---|---|
| 입장권이 맞지 않음 | 인트라넷 토큰과 스크립트 속성 IMG_TOKEN 이 같은지 |
| 서버에 IMG_TOKEN 이 아직 없어요 | 3번 다시 |
| 입장권 날짜가 오늘이 아니에요 | 인트라넷에서 ① 다시 준비 |
| 프로젝트 폴더 밖에 있어요 | 인트라넷에서 사진을 다시 고르고 ① 다시 준비 |
| Gemini … 403 / 429 | 키·결제·사용량 확인 (Google AI Studio) |
| 그림이 안 왔어요 (SAFETY) | 요청 글·사진 바꾸기 (사람 얼굴 사진 빼기) |

생성 기록은 간편견적 접수 시트의 **'인트라넷 시안'** 탭에 한 줄씩 남습니다.
