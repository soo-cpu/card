# 홈퍼니싱 인트라넷 1단계 설치 안내 (대표 PC에서 한 번)

> 원본 결재 서류(공유드라이브 「0. 홈퍼니싱」)는 건드리지 않습니다. 이 스크립트는 **새 시트 2개 + 증빙 폴더 1개**를 대표 드라이브에 만듭니다.

## 1. 스크립트 만들기 (10분)
1. **soo@artico-studio.com** 으로 로그인 → https://script.google.com → **새 프로젝트**
2. 프로젝트 이름: `홈퍼니싱 인트라넷`
3. 왼쪽 `Code.gs` 내용을 지우고 이 폴더의 **Code.gs** 를 통째로 붙여넣기
4. `+` → **스크립트** → 이름 `Catalog` → **Catalog.gs** 내용 붙여넣기 (견적 단가표 기본값)
5. `+` → **HTML** → 이름 `Index` → **Index.html** 내용 붙여넣기
6. ⚙️ 프로젝트 설정 → "appsscript.json 매니페스트 파일 표시" 체크 → **appsscript.json** 내용 붙여넣기

## 2. 처음 실행 (시트 만들기)
1. 위쪽 함수 선택에서 `setup` → **실행** → 권한 허용
2. 실행 로그에 나온 링크 2개 확인
   - `홈퍼니싱 인트라넷 DB` : 직원 / 결재(결과 시트) / 결재_지출내역 / 현장
   - `홈퍼니싱 민감정보(대표 전용) — 공유 금지` : 직원_민감 / 결재_계좌 → **누구와도 공유하지 마세요**

## 3. 웹앱 배포
1. **배포 → 새 배포 → 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **artico-studio.com 도메인 사용자**
3. 나온 웹앱 주소를 직원에게 공유 (직원은 시트 파일 권한이 필요 없음)

## 4. 직원 등록
- 인트라넷 → **인사** → 직원마다 입사일·회사이메일·연락처·담당업무 입력
- 민감정보 칸(주민번호·주소·급여·계좌·근로계약서 링크)은 대표 전용 시트에만 저장
- 근로계약서는 「2. 급여.인사관련 › 3)근로계약서,퇴직연금,입퇴사」 원본의 **링크만** 붙여 넣기

## 동작
- 직원 기안 → 결과 시트에 `결재 대기`로 기록 → **soo@artico-studio.com 으로 메일** → 대표 승인/반려 → 결과 시트 갱신 + 기안자에게 결과 메일
- 문서번호는 원본과 같은 `26-10-01` 형식, 현장코드는 `S26-001` 형식
- 계좌번호는 메일·직원 화면에 나오지 않음

## 견적 모듈 (2026-10-29 추가)
- `setup` 을 다시 실행하면 고객·단가표·견적·견적_항목 시트가 추가되고, 단가표가 비어 있을 때만 v.15 단가표 184개를 넣습니다(기존 데이터 유지).
- **원가**는 DB의 `단가표` 시트 '원가' 칸에 대표가 직접 입력 → 대표 화면에만 원가·마진율 표시.

## 원가 가져오기 (2026-10-30 추가 · 대표 PC에서 한 번)
1. 스크립트 편집기 위쪽 함수 선택에서 `setup` → 실행 (새 칸 '실비·고정·원가근거'가 생김)
2. 함수 선택에서 `importCostsV15` → 실행 → 로그에 "184개 항목 원가 반영"이 나오면 끝
   - 원가는 대표 **내 드라이브**의 「단가표 원가 v.15 (대표 전용 · 공유 금지)」 시트에서 읽어 옵니다. 이 시트는 누구와도 공유하지 마세요.
   - 원가는 GitHub 코드에 넣지 않았습니다.
3. 이후 원가를 바꾸려면 DB의 `단가표` 시트 '원가' 칸을 직접 고치면 됩니다.

## 원가 공개 범위 (2026-10-30 대표 결정)
- 직원 견적 화면: 원가·마진율(25~30%, 목표 28%) 모두 보임.
- 고객 상담 모드(다음 단계): 원가·마진·업체 단가·마진 표기(0.025 같은 암호 포함)를 데이터로도 보내지 않음. 견적서 PDF에도 넣지 않음.

## 초기 데이터 넣기 (2026-10-30 추가 · 대표 PC에서 한 번)
공유드라이브 「홈퍼니싱 본사 결재 서류 › 0. 홈퍼니싱」을 **읽기만** 해서 만든 표 3개가 대표 내 드라이브 「인트라넷 초기 데이터 (대표 전용)」 폴더에 있습니다.
1. `setup` 실행 (현장·업체·서식 시트가 새로 생김)
2. 함수 선택에서 `importSeed` → 실행 → 로그에 "현장 111곳 · 업체 159곳 · 서식 61개 가져옴"
3. 다시 실행해도 중복으로 들어가지 않습니다.
- 현장: 2020~2026년 현장 폴더 111곳, 현장코드 S20-001~S26-013 (새 현장은 S26-014부터)
- 업체: 26년 기안품의서의 업체명·품목·연락처 159곳 (계좌번호 없음, 개인 이름은 성만)
- 서식: 본사 서식 원본 링크 61개

## 인사 — 연차 사용·급여 인상 이력 (2026-10-30 추가)
1. 스크립트에 새 Code.gs·Index.html 붙여넣기 → `setup` 한 번 실행
   - DB에 `연차사용` 시트, 민감정보(대표 전용) 시트에 `급여이력` 시트가 생깁니다. 기존 데이터는 그대로.
2. 인사 → 직원 이름 누르기
   - **연차 사용 내역**: 승인된 휴가신청서는 자동 표시. 인트라넷 전에 쓴 연차는 '연차 사용 추가'로 직접 입력 (연차·반차만 잔여에서 빠짐).
   - **급여·인상 이력** (대표만): 적용일·구분(입사/정기인상/수시인상/승진/조정/삭감)·연봉 입력 → 인상액·인상률 자동 계산, 최신 연봉이 '급여(연봉)' 칸에 자동 반영.
   - 주민번호·주소·계좌·근로계약서 링크는 기존처럼 '민감정보' 칸 (대표 전용 시트).
3. 직원은 본인 이름을 누르면 **본인 연차 내역만** 봅니다. 급여·주민번호는 직원 화면·메일에 나오지 않습니다.

## 과거 기안품의서 가져오기 (2026-10-30 추가 · 대표 PC에서)

1. 새 **Code.gs · Index.html · appsscript.json** 붙여넣기 (appsscript.json 에 Drive API 사용이 들어 있음)
2. `setup` 실행 → 함수 선택 `importApprovalHistory` → 실행 → 권한 허용(드라이브)
   - 로그에 "과거 기안품의서 가져오기 완료"가 나오면 끝. "한 번 더 실행하세요"가 나오면 같은 함수를 다시 실행 (이어서 하고 중복 없음).
   - 원본을 내 드라이브에 임시 구글시트 사본으로 만들어 읽고, 다 읽으면 사본은 휴지통으로 보냅니다.

4. 결재함: 검색(현장·제목·업체·기안자), 연도·상태·종류 거르기, 건수와 합계 금액 표시, 100건씩 더 보기.
