# 홈퍼니싱 인트라넷 1단계 설치 안내 (대표 PC에서 한 번)

> 원본 결재 서류(공유드라이브 「0. 홈퍼니싱」)는 건드리지 않습니다. 이 스크립트는 **새 시트 2개 + 증빙 폴더 1개**를 대표 드라이브에 만듭니다.

## 1. 스크립트 만들기 (10분)
1. **soo@artico-studio.com** 으로 로그인 → https://script.google.com → **새 프로젝트**
2. 프로젝트 이름: `홈퍼니싱 인트라넷`
3. 왼쪽 `Code.gs` 내용을 지우고 이 폴더의 **Code.gs** 를 통째로 붙여넣기
4. `+` → **스크립트** → 이름 `Catalog` → **Catalog.gs** 내용 붙여넣기 (견적 단가표 기본값)
5. `+` → **HTML** → 이름 `Index` → **Index.html** 내용 붙여넣기
6. ⚙️ 프로젝트 설정 → "appsscript.json 매니페스트 파일 표시" 체크 → **appsscript.json** 내용 붙여넣기

## 2. 처음 실행 (시트 만들기)
1. 위쪽 함수 선택에서 `setup` → **실행** → 권한 허용
2. 실행 로그에 나온 링크 2개 확인
   - `홈퍼니싱 인트라넷 DB` : 직원 / 결재(결과 시트) / 결재_지출내역 / 현장
   - `홈퍼니싱 민감정보(대표 전용) — 공유 금지` : 직원_민감 / 결재_계좌 → **누구와도 공유하지 마세요**

## 3. 웹앱 배포
1. **배포 → 새 배포 → 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **artico-studio.com 도메인 사용자**
3. 나온 웹앱 주소를 직원에게 공유 (직원은 시트 파일 권한이 필요 없음)

## 4. 직원 등록
- 인트라넷 → **인사** → 직원마다 입사일·회사이메일·연락처·담당업무 입력
- 민감정보 칸(주민번호·주소·급여·계좌·근로계약서 링크)은 대표 전용 시트에만 저장
- 근로계약서는 「2. 급여.인사관련 › 3)근로계약서,퇴직연금,입퇴사」 원본의 **링크만** 붙여 넣기

## 동작
- 직원 기안 → 결과 시트에 `결재 대기`로 기록 → **soo@artico-studio.com 으로 메일** → 대표 승인/반려 → 결과 시트 갱신 + 기안자에게 결과 메일
- 문서번호는 원본과 같은 `26-10-01` 형식, 현장코드는 `S26-001` 형식
- 계좌번호는 메일·직원 화면에 나오지 않음

## 견적 모듈 (2026-10-29 추가)
- `setup` 을 다시 실행하면 고객·단가표·견적·견적_항목 시트가 추가되고, 단가표가 비어 있을 때만 v.15 단가표 184개를 넣습니다(기존 데이터 유지).
- **원가**는 DB의 `단가표` 시트 '원가' 칸에 대표가 직접 입력 → 대표 화면에만 원가·마진율 표시.

## 원가 가져오기 (2026-10-30 추가 · 대표 PC에서 한 번)
1. 스크립트 편집기 위쪽 함수 선택에서 `setup` → 실행 (새 칸 '실비·고정·원가근거'가 생김)
2. 함수 선택에서 `importCostsV15` → 실행 → 로그에 "184개 항목 원가 반영"이 나오면 끝
   - 원가는 대표 **내 드라이브**의 「단가표 원가 v.15 (대표 전용 · 공유 금지)」 시트에서 읽어 옵니다. 이 시트는 누구와도 공유하지 마세요.

3. 이후 원가를 바꾸려면 DB의 `단가표` 시트 '원가' 칸을 직접 고치면 됩니다.
