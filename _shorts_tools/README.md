# 쇼츠 제작 도구

- `render*.py`: 위 3D / 아래 현장 사진 쇼츠 영상 (1080x1920, 30fps). 장면 목록 `SC`만 바꾸면 새 편.
- `music.py`: 음악 v1 (잔잔한 피아노, 1편에 사용)
- `music_v2.py`: 음악 v2 (신나는 하우스 팝 124BPM, 2편에 사용). 장면 전환 2.9초 = 6박에 맞춤, 첫 장면 2.6초에 드롭.
- `decode.py`, `sheet.py`: 드라이브에서 받은 사진 풀기, 사진 한눈에 보기
