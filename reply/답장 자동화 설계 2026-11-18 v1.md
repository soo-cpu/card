## 2. 메일 시험판이 하는 일

1. 10분마다 회사 받은편지함에서 **최근 2일, 아직 '자동답장' 라벨이 없는 메일**을 최대 10건 본다.
2. **건너뛰기**: 내가 보낸 메일 / no-reply·알림 주소 / 광고·뉴스레터(수신거부 머리글) / `[간편견적`·`[사람인]` 제목 / 이미 초안이 있는 메일 → `자동답장/해당없음`
3. **분류**: 제목+본문 앞부분의 낱말로 10가지 중 1개를 고른다 (4장 표). 안 맞으면 아무것도 안 함.
4. **초안 만들기**: 시험 모드가 꺼져 있고, **그 유형 문구가 승인된 경우에만** 원래 메일에 대한 '답장 초안'을 만든다 → `자동답장/초안 만듦`. 형이 채울 칸(⟦ ⟧)이 있는 유형은 `자동답장/확인필요`도 붙인다.
5. **기록**: 구글 시트 '답장 자동화 기록'에 시각·보낸 사람·제목·유형·처리를 한 줄씩 남긴다.

### 안전장치
- 코드에 **보내기·전달·삭제 명령이 없다** (`send`, `forward`, `reply(`, `moveToTrash` 없음 — 자동 테스트로 매번 확인).
- 처음엔 `DRY_RUN = true` → 분류·라벨·기록만. 초안도 안 만든다.
- 문구별 승인 스위치 `APPROVED.T01~T10` → 승인한 것만 켠다.
- 한 번에 10건까지만. 이미 초안이 있거나 라벨이 붙은 메일은 다시 안 건드린다.
- 금액·날짜를 문구가 **약속하지 않는다.** 금액은 간편 견적 링크로, 날짜는 "담당 실장이 확인 후 연락"으로.
- 서류 첨부(T07)와 견적서 날짜(T04)는 형이 채워야 하는 ⟦ ⟧ 칸이 있고, 맨 위에 "보내기 전 채우고 이 줄 지우기" 줄이 붙는다.

| 9 | T09 공사 일정 문의 | (공사·착공·완공·공정·시공) + (일정·언제·기간·며칠·끝나·시작) |
| 10 | T08 실측·방문 일정 확인 | (실측·방문·미팅·상담·현장) + (일정·시간·날짜·몇 시·가능·확인·언제) |

- 시험: 가짜 고객 메일 15건 모두 맞게 분류, **실제 받은편지함 최근 50건 중 잘못 고른 것 0건** (처음엔 한국AI통신 '사업자등록증이 확인되지 않음' 알림을 서류 요청으로 잘못 골라서, 요청 낱말에서 '주세요'를 빼고 고침).
- 낱말 규칙이라 단순하고 예측 가능하다. 틀려도 **초안 1개가 생길 뿐 나가지는 않는다.** 한 달 써 보고 놓친 메일·틀린 메일을 보고 낱말을 고친다.

## 5. 설치 방법 (형, 회사 계정으로 10분)

1. 회사 계정(soo@artico-studio.com)으로 <https://script.google.com> → **새 프로젝트** → 이름 `답장 초안 봇`
2. `Code.gs` 내용을 지우고 `gmail-draft-bot.gs` 내용을 통째로 붙여넣기 → 저장
   (코드 주소: https://raw.githubusercontent.com/soo-cpu/card/claude/auto-reply-automation-design-hepykj/reply/gmail-draft-bot.gs → 전체 선택·복사)
3. 위쪽 함수 고르는 칸에서 `testRunOnce` → **실행** → 권한 허용 (Gmail·시트 권한. '확인되지 않은 앱' 경고가 나오면 고급 → 이동)
4. 실행 기록에서 결과 확인, 드라이브에 생긴 시트 **'답장 자동화 기록'** 확인
5. `installTrigger` 실행 → 10분마다 자동 (끄려면 `removeTrigger`)

### 단계별로 켜기
| 단계 | 설정 | 기간 | 하는 일 |
|---|---|---|---|
| ① 시험 분류 | `DRY_RUN: true` | 1주 | 라벨·기록만. 시트를 보고 잘못 고른 메일 확인 |
| ② 승인 유형만 초안 | `DRY_RUN: false`, 승인한 T번호만 `true` | 2~3주 | 임시보관함 초안을 형이 고쳐서 보내기 |
| ③ (선택) Claude 분류 | 낱말 대신 Claude가 유형·이름·요청 내용을 읽음 | 필요할 때 | 문구를 메일 내용에 맞게 조금씩 바꿈. API 비용 생김 |

## 6. 카카오톡 · 가능한 방법 한 장 비교

> [!warning] 전제
> 카카오는 **개인 카카오톡 채팅에 자동으로 답하는 공식 API를 열어 두지 않았다.** 개인 톡 자동 답장은 모두 비공식 방법(화면 매크로·알림 가로채기)뿐이다.

| 방법 | 어떻게 | 좋은 점 | 나쁜 점 | 위험 | 비용·난이도 | 추천 |
|---|---|---|---|---|---|---|
| **A. 카카오톡 채널 자동응답** | 회사 '카카오톡 채널'을 만들고 관리자센터에서 키워드 자동응답·운영시간 외 안내·첫 인사 설정 | 공식 기능, 24시간 즉시 답, 견적·자료·일정 질문을 버튼으로 안내 가능, 홈페이지·명함 '카톡 상담' 버튼과 연결 | **고객이 채널로 말을 걸어야** 함(개인 톡엔 안 됨), 정해진 답만 가능 | 낮음 | 기본 기능은 무료로 알려져 있음(가입 때 확인), 설정 반나절 | ⭐ 1순위 |
| **B. 채널 + 챗봇(카카오 i 오픈빌더) + Claude** | A의 채널에 챗봇을 붙이고, 질문을 우리 서버(Claude)로 보내 답 만들기 | 자유로운 질문에도 답, 간편견적 계산까지 연결 가능 | 개발·서버 필요, 챗봇 심사, AI가 틀린 답을 바로 보낼 수 있음 | 중간 (오답·개인정보) | 개발 수일 + API 비용 | A가 자리 잡은 뒤 |
| **C. 반자동 · '나와의 채팅'** | 형이 받은 톡을 Claude에 붙여넣거나 말하면, Claude가 답장 문구를 만들어 카톡 '나와의 채팅'으로 보냄 → 형이 복사해 보냄 | 공식 연결(PlayMCP)만 사용, 개인 톡에도 쓸 수 있음, 오늘의집 상담에서 이미 쓰는 흐름 | 형이 복사·붙여넣기 한 번 해야 함 | 낮음 | 지금 바로 | ⭐ 개인 톡용 |
| **D. 휴대폰 키보드 상용구** | 삼성 키보드 '텍스트 단축키' / 아이폰 '텍스트 대치'에 뻔한 답 10개 등록 (예: `ㄱㅈ` → 견적 안내 문구) | 공짜, 5분, 어느 앱에서나 됨, 위험 없음 | 자동은 아님 (형이 고르고 보냄) | 없음 | 무료 | ⭐ 바로 하기 좋음 |
| E. PC 카톡 매크로 | PC 카카오톡 화면을 프로그램이 읽고 대신 입력·전송 (오토핫키·파이썬 등) | 개인 톡도 완전 자동 | 화면 바뀌면 고장, PC 계속 켜 둬야 함, **엉뚱한 방에 보낼 수 있음** | **높음**: 카카오 운영정책상 비정상 자동화 → 계정 이용 제한 가능, 오발송, 고객 대화 유출 | 무료지만 관리 부담 큼 | ✕ 비추천 |
| F. 안드로이드 알림 자동응답 앱 | 카톡 알림을 앱이 읽고 알림의 '답장'으로 자동 전송 | 휴대폰만 있으면 됨 | 비공식 앱이 모든 알림(고객 대화)을 읽음, 업데이트 때 자주 고장 | **높음**: 계정 제한 가능성, 개인정보, 엉뚱한 자동 답 | 무료~소액 | ✕ 비추천 |

> [!tip] 추천 조합
> **고객 문의 → 카카오톡 채널(A)로 모으기** (홈페이지·명함·간편견적의 '카톡 상담' 버튼을 채널 주소로), **개인 톡 → 반자동(C) + 키보드 상용구(D)**. 매크로(E·F)는 쓰지 않는다.
> 업무 알림(잔금일·공정 안내 등)을 보내는 건 답장과 별개로 **카카오 알림톡**(대행사 통한 유료 발송)이 공식 방법이다 — [[회사 서버 이전 설계서]]의 알림톡 계획과 이어서 본다.
