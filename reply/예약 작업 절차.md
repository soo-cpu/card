# 답장 초안 예약 작업 절차 (Claude용)

형 결정 2026-11-18: PC 설치 대신 **Claude 예약 작업이 회사 Gmail을 직접 확인**. 평일 9~18시 1시간마다, 승인된 문구 10개로 **바로 초안**, 초안이 생길 때만 카톡(나와의 채팅) 알림.

## 절대 규칙
- 메일을 **보내지·전달하지·지우지 않는다.** Gmail 도구는 `search_threads`, `get_thread`, `list_drafts`, `create_draft`, `label_thread` 만 쓴다. `send_message`, `reply`, `forward`, `trash_*` 금지.
- 판단(건너뛰기·유형·본문)은 `decide.js` 결과만 따른다. 문구를 고쳐 쓰지 않는다.

## 순서
1. 코드 받기 (작업 폴더에서):
   ```
   B=https://raw.githubusercontent.com/soo-cpu/card/claude/auto-reply-automation-design-hepykj/reply
   mkdir -p bot && curl -sf $B/gmail-draft-bot.gs -o bot/gmail-draft-bot.gs && curl -sf $B/decide.js -o bot/decide.js
   ```
2. Gmail `search_threads`: `in:inbox newer_than:1d -category:promotions -category:social -label:자동답장` (pageSize 20, SUMMARY)
3. `list_drafts`(pageSize 50) → 초안이 있는 threadId 모음
4. 각 스레드 `get_thread`(PLAIN_TEXT) → 마지막 메시지 기준으로 JSON 한 줄:
   `{threadId, messageId(마지막 메시지 id), from("이름 <주소>"), subject, body(앞 3000자), listUnsubscribe(false), lastFromMe(보낸 사람이 soo@artico-studio.com 이면 true), hasDraft}`
5. `node bot/decide.js < mails.json`
6. `action: draft` 마다 `create_draft`: to=[to], subject, body, replyToMessageId=messageId → `label_thread` [Label_1, Label_2] (+ needsFill이면 Label_3)
   `action: skip` 은 `label_thread` [Label_1, Label_4]
   (라벨: Label_1 자동답장 · Label_2 초안 만듦 · Label_3 확인필요 · Label_4 해당없음)
7. 초안이 1개 이상이면 카톡 `KakaotalkChat-MemoChat` 한 통 (200자 안):
   `📧 답장 초안 N건 (임시보관함)\n- 유형 · 보낸 사람 · 제목 앞부분\n⟦⟧ 칸 있는 건 채워서 보내세요`
   0건이면 카톡 보내지 않음.
8. 오류(코드 못 받음, Gmail 실패)가 나면 초안을 만들지 말고 카톡 1통: `⚠️ 답장 초안 예약 작업 오류: (한 줄)`
