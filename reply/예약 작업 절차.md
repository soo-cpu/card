# 메일 자동답장 예약 작업 절차 (Claude용)

- 2026-11-18: Claude 예약 작업(이 대화)이 회사 Gmail을 직접 확인. 평일 9~18시 매시 7분.
- **2026-11-19 형 결정: 초안 저장 대신 자동 발송.**

## 규칙
1. 문의 메일이 오면 답장을 **바로 발송** (Gmail `reply`, messageId = 마지막 메시지). 임시보관함에 저장하지 않는다.
2. 답장 맨 끝: "자동 발송된 안내 메일입니다. 궁금하신 점은 전화로 한 번 더 확인 부탁드립니다." (`decide.js`가 붙임)
3. 금액·할인·공사 기간 약속은 넣지 않는다. 문구 10개에 없고, `decide.js`가 본문을 한 번 더 검사해 걸리면 보내지 않는다(`manual`).
4. 발송하면 카톡 나와의 채팅: `📨 자동답장 보냄: 이름(주소) · 제목 앞부분 · 유형`
5. 같은 사람에게 **하루 1번만**. 광고·스팸·뉴스레터·no-reply·자동응답·반송 메일에는 답하지 않는다.
6. T04(견적서 날짜)·T07(서류 첨부)은 형이 채워야 해서 **보내지 않고** 카톡으로 "직접 답장 필요"만 알린다.
7. 판단은 `decide.js` 결과만 따른다. 문구를 고쳐 쓰지 않는다. 전달·삭제는 하지 않는다.

## 순서
1. Gmail `search_threads`: `in:inbox newer_than:1d -category:promotions -category:social -label:자동답장` (SUMMARY)
2. 각 스레드 `get_thread` → 마지막 메시지 기준 JSON:
   `{threadId, messageId, from("이름 <주소>"), subject, body(앞 3000자), listUnsubscribe:false, lastFromMe(보낸 사람이 soo@artico-studio.com), repliedToday}`
   - repliedToday: `search_threads` `in:sent to:<주소> newer_than:1d "자동 발송된 안내 메일입니다"` 결과가 있으면 true
3. `node /home/user/card/reply/decide.js < mails.json`
4. `send` → `reply`(messageId, body) → `label_thread` [Label_1, Label_5] → 카톡 알림
   `manual` → `label_thread` [Label_1, Label_3] → 카톡 "✋ 직접 답장 필요: 누구 · 이유"
   `skip` → `label_thread` [Label_1, Label_4]
   (라벨: Label_1 자동답장 · Label_3 확인필요 · Label_4 해당없음 · Label_5 자동답장/보냄)
5. 보낸 것·직접 처리할 것이 0건이면 카톡 보내지 않고 한 줄로 끝낸다.
6. 오류가 나면 보내지 말고 카톡 1통: `⚠️ 자동답장 오류: (한 줄)`
