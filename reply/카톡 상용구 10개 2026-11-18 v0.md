# 카톡 상용구 10개 2026-11-18 v0

관련: [[답장 자동화 설계 2026-11-18 v1]] · 메일 문구 T01~T10을 카톡용으로 짧게 줄임 · 금액·날짜 약속 없음

> [!summary] 쓰는 법
> 휴대폰 키보드에 **단축어**를 등록해 두면, 카톡에서 `/견적` 처럼 치는 순간 키보드 위 추천 칸에 문구가 뜹니다 → 누르면 통째로 들어감 → 고객 이름만 바꾸고 보내기.
> 자동 발송이 아니라 **형이 골라서 보내는 방식**이라 카카오 계정 위험이 없습니다.

## 등록 방법

**삼성(갤럭시)**
설정 → 일반 → 삼성 키보드 설정 → 스마트 타이핑 → **텍스트 단축키** → `+` → 단축어 / 확장 문구 입력 → 저장
(메뉴 이름은 기종마다 조금 다를 수 있음. 설정 검색창에 "텍스트 단축키")

**아이폰**
설정 → 일반 → 키보드 → **텍스트 대치** → `+` → 문구 / 단축키 입력 → 저장

## 상용구 10개

| 단축어 | 언제 |
|---|---|
| `/견적` | 아파트 전체 리모델링 견적 문의 |
| `/부분` | 욕실·주방·도배 등 부분 공사 문의 |
| `/상가` | 상가·사무실 견적 문의 |
| `/견적서` | "견적서 언제 와요?" (○○ 칸 채우기) |
| `/소개` | 회사소개서 요청 |
| `/사례` | 시공 사례 요청 |
| `/서류` | 사업자등록증 등 서류 요청 (파일은 따로 보내기) |
| `/실측` | 실측·방문 일정 확인 |
| `/공사` | 공사 일정 문의 |
| `/변경` | 일정 변경·취소 요청 |

### /견적
```text
안녕하세요, 홈퍼니싱(아르띠꼬 스튜디오)입니다. 문의 감사합니다.
정확한 견적을 위해 ① 주소(단지·동) ② 평수·욕실 수 ③ 공사 범위 ④ 희망 시기 ⑤ 집 사진(있으시면) 알려 주세요.
대략적인 금액은 1분 간편 견적에서 먼저 보실 수 있어요 👉 https://soo-cpu.github.io/card/estimate/
확인 후 담당 실장이 실측 일정 잡아 연락드릴게요.
```

### /부분
```text
안녕하세요, 홈퍼니싱(아르띠꼬 스튜디오)입니다. 부분 공사 문의 감사합니다.
① 주소·평수 ② 공사할 곳(욕실·주방 등) ③ 해당 공간 사진 2~3장 ④ 희망 시기 알려 주시면 맞춰서 안내드릴게요.
```

### /상가
```text
안녕하세요, 홈퍼니싱(아르띠꼬 스튜디오)입니다. 상업 공간 문의 감사합니다.
① 위치·면적 ② 업종·용도 ③ 철거 필요 여부 ④ 오픈 예정일 ⑤ 도면·사진(있으시면) 알려 주세요.
회사소개서 👉 https://soo-cpu.github.io/card/site/files/company-profile.pdf
시공 사례 👉 https://soo-cpu.github.io/card/site/works/
```

### /견적서
```text
견적서 기다리게 해 드려 죄송합니다. 실측 내용으로 정리 중이고, ○○까지 보내드릴게요.
궁금하신 점은 대표번호 1566-5904로 편하게 연락 주세요.
```

### /소개
```text
요청하신 회사소개서(지명원)입니다.
👉 https://soo-cpu.github.io/card/site/files/company-profile.pdf

```

### /사례
```text
시공 사례는 여기 사진과 함께 모아 두었어요 👉 https://soo-cpu.github.io/card/site/works/
비슷한 평수·단지 사례가 더 필요하시면 말씀해 주세요. 골라서 보내드릴게요.
```

### /서류
```text
요청하신 서류 보내드립니다. 다른 서류가 더 필요하시면 말씀해 주세요.
```

### /실측
```text
일정 문의 감사합니다. 담당 실장 일정과 맞춰 본 뒤 확정된 날짜·시간을 다시 연락드릴게요. 방문 전날에도 한 번 더 안내드립니다.
```

### /공사
```text
공사 일정 문의 감사합니다. 담당 실장이 공정표 기준으로 진행 상황과 남은 일정을 정리해 연락드릴게요.
급하시면 대표번호 1566-5904로 전화 주세요.
```

### /변경
```text
일정 변경 요청 잘 받았습니다. 가능한 날짜·시간대를 2~3개 알려 주시면 담당 실장 일정과 맞춰 새로 잡아 드릴게요.
```
